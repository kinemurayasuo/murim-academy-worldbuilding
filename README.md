# 무림아카데미학원 세계관 페이지

전통과 현대가 공존하는 무림 세계의 세계관을 정리한 웹사이트입니다.

## 🌟 특징

- **현대 무협 세계관**: 스마트폰과 무공이 공존하는 2025년 대한민국
- **카테고리별 정리**: 세계관, 세력, 인물, 스킬, 시스템, 스토리로 체계적 분류
- **검색 기능**: 원하는 문서를 빠르게 찾을 수 있는 검색 시스템
- **다크 모드**: 라이트/다크 테마 지원
- **반응형 디자인**: 모바일부터 데스크톱까지 최적화

## 🛠️ 기술 스택

- **Frontend**: React + TypeScript
- **Styling**: Tailwind CSS + shadcn/ui
- **Build Tool**: Vite
- **Markdown**: ReactMarkdown
- **Deployment**: GitHub Pages

## 🚀 로컬 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 빌드
npm run build
```
