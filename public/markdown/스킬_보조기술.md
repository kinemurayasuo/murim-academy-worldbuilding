## 🎯 보조 기술 조합

### 대장장이 + 연단술
```
신병 단조 + 영약 제조 = 약병 (SS)
- 약효 있는 무기
- 베이면 치유
- 상처 회복
```

### 요리 + 의술
```
천하제일 요리 + 천의신침 = 식의 쌍절 (SSS)
- 음식으로 모든 병 치료
- 먹기만 하면 회복
```

### 진법 + 부적
```
진법 구축 + 부적 제작 = 진부 결합 (SS+)
- 부적으로 즉시 진법
- 휴대 가능한 진법
```
