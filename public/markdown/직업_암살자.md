# 암살자 (暗殺者) 직업

## 📋 개요

**직업명**: 암살자 (暗殺者)
**주 무기**: 암기, 단검
**특징**: 은밀함, 일격필살, 기습
**대표 인물**: 그림자왕, 무영살수, 혈영암살단주

### 장점
1. **일격필살**: 급소 공격 특화
2. **은밀함**: 기척 완벽 차단
3. **기습**: 선제공격 100%
4. **정보**: 첩보 능력 우수
5. **도주**: 탈출 능력 최고

### 단점
1. **정면 약함**: 정면 승부 불리
2. **실패 시 위험**: 기습 실패 시 불리
3. **윤리적 문제**: 사회적 악명
4. **심리적 부담**: 살인 죄책감
5. **신뢰 부족**: 동료 신뢰 어려움
