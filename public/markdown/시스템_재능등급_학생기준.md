# 재능 등급 기준 (학생 버전)

---

## 📊 재능 등급 체계 (현실 기준)

### 학생 재능 한계

```
S급: 천재 (백년에 한 명)
- 미래 대종사급 가능
- 학생 중 최고 재능
- 주인공급 천재

A급: 수재 (십년에 한 명)
- 미래 종사급 가능
- 학원 상위 1%
- 엘리트

B급: 우수 (평범한 천재)
- 미래 현경급 가능
- 학원 상위 10%
- 재능 있음

C급: 보통 (일반 수재)
- 미래 절정급 가능
- 학원 평균
- 노력형

D급: 평범 (보통 사람)
- 미래 화경급 한계
- 노력 필요
- 일반인

E급: 하위 (재능 부족)
- 미래 선천경 한계
- 매우 노력 필요

F급: 최하위 (재능 없음)
- 무공 부적합
- 다른 길 찾기
```

---

## ⚠️ 절대 규칙

**EX급은 존재하지 않음 (학생 기준)**
- EX급은 세계관 최강자 전용
- 학생은 아무리 천재라도 S급이 한계
- "재능 한계 EX급" = 잘못된 설정

**재능 ≠ 현재 실력**
- 재능 S급이어도 현재는 학생
- 미래 가능성일 뿐
- 지금은 미완성

## 🎯 9명 캐릭터 재능 재조정

### 최상위 (S급) - 진짜 천재 1명
**강아란**
- 재능 한계: S급
- 현재 등급: A급
- 미래: 대종사 가능
- 특징: 검술 천재

### 상위 (A급) - 수재 2명
**혈소연**
- 재능 한계: A급
- 현재 등급: A급
- 미래: 종사급 가능
- 특징: 균형잡힌 수재

**흑영**
- 재능 한계: A급
- 현재 등급: B+급
- 미래: 종사급 가능
- 특징: 암살 천재

### 중상위 (B급) - 우수 3명
**설무연**
- 재능 한계: B급
- 현재 등급: B+급
- 미래: 현경급 가능
- 특징: 직관력 특수

**진대식**
- 재능 한계: B급
- 현재 등급: B-급
- 미래: 현경급 가능
- 특징: 힘 특화

**소하린**
- 재능 한계: B급 (+ 특수체질)
- 현재 등급: B급
- 미래: 현경급 (치유 특화)
- 특징: 의술 천재

### 중위 (C급) - 보통 2명
**백서연**
- 재능 한계: C급
- 현재 등급: B-급
- 미래: 절정급 가능
- 특징: 지능으로 보완

**장미설**
- 재능 한계: C급
- 현재 등급: C+급
- 미래: 절정급 (독술 특화)
- 특징: 독술 재능

### 하위 (D급) - 평범 1명
**운소아**
- 재능 한계: D급
- 현재 등급: D+급
- 미래: 화경급 한계
- 특징: 행운으로 보완 (행운은 S급)

## 📈 전투력 재조정 (재능 기준)

### S급 재능 (강아란)
- 현재 전투력: 52,000 (A급)
- 미래 전망: 1,000,000+ (대종사)
- 성장 배율: ×20

### A급 재능 (혈소연, 흑영)
- 현재 전투력: 42,000~51,500
- 미래 전망: 500,000~800,000 (종사)
- 성장 배율: ×15

### B급 재능 (설무연, 진대식, 소하린)
- 현재 전투력: 35,000~45,000
- 미래 전망: 100,000~300,000 (현경)
- 성장 배율: ×10

### C급 재능 (백서연, 장미설)
- 현재 전투력: 30,000~33,000
- 미래 전망: 50,000~100,000 (절정)
- 성장 배율: ×3

### D급 재능 (운소아)
- 현재 전투력: 8,000
- 미래 전망: 20,000~30,000 (화경)
- 성장 배율: ×3 (행운 보정)

## 🎓 학원 등급 분포

```
S급 재능: 1명 (0.1%) - 강아란
A급 재능: 2명 (1%) - 혈소연, 흑영
B급 재능: 3명 (10%) - 설무연, 진대식, 소하린
C급 재능: 2명 (30%) - 백서연, 장미설
D급 재능: 1명 (50%) - 운소아
E-F급: 없음 (입학 불가)
```

---

## ⚖️ 재능 vs 노력

### 재능의 한계
- S급도 노력 없으면 B급 실력
- D급도 노력하면 C급 돌파 가능
- 재능은 천장, 노력은 계단

### 현재 실력 = 재능 × 노력 × 환경
- 강아란: S급 재능 × 200% 노력 = A급 실력
- 백서연: C급 재능 × 150% 노력 = B-급 실력
- 운소아: D급 재능 × 80% 노력 + 행운 = D+급 실력

## 🚫 금지 사항

**❌ 학생에게 절대 금지**:
- EX급 재능 (세계관 최강자 전용)
- SSS급 재능 (전설급 전용)
- SS급 재능 (절정고수 전용)

**✅ 학생 허용 범위**:
- 최대: S급 (백년에 한 명 천재)
- 일반 천재: A~B급
- 평범: C~D급

## 📝 재능 판정 기준

### S급 판정 조건 (모두 충족)
1. 무공 이해도: 천재적
2. 습득 속도: 10배 이상
3. 응용력: 독자 무공 창조
4. 잠재력: 대종사급 가능
5. 희귀도: 백년에 한 명

### A급 판정 조건 (3개 이상)
1. 무공 이해도: 뛰어남
2. 습득 속도: 5배 이상
3. 응용력: 변형 가능
4. 잠재력: 종사급 가능
5. 희귀도: 십년에 한 명

### B급 판정 조건 (2개 이상)
1. 무공 이해도: 좋음
2. 습득 속도: 3배
3. 응용력: 부분 변형
4. 잠재력: 현경급 가능
5. 희귀도: 백 명 중 한 명
