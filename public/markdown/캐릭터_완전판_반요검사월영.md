- 베인 자리마다 눈꽃 흩날림

【절대영도 발도술】
난이도: ★★★★★
- 칼집에서 뽑는 순간 주변 시간 정지(착각)
- 실제론 극저온으로 모든 동작 둔화
- 본인만 정상 속도로 움직임
- 상대 입장에서는 순간이동처럼 보임

【빙옥섬광검 (氷玉閃光劍)】
난이도: ★★★★☆
- 발도 후 빙설 속성 검기 방출
- 직선상 모든 것을 베고 얼림
- 사거리: 50m
- 관통력 극대

【겨울밤의 진혼곡】
난이도: ★★★★★
- 검무 + 빙설술 + 요력 全開
- 범위 내 모든 적 동결 + 베기
- 마치 폭풍설 속 검의 난무
- 사용 후 기절 (최후의 수단)
```

## 7. 핵심 성격 키워드 (Core Personality Keywords)

```
■ 과묵함 / 침묵 / 말 아끼기
  - 불필요한 말 하지 않음
  - 필요한 말만 간결하게
  - 침묵이 편한 사람

■ 냉정함 / 이성적 / 감정 억제
  - 감정 표현 최소화
  - 항상 냉정한 판단
  - 하지만 내면은 뜨거움

■ 책임감 / 의무감 / 완벽주의
  - 맡은 일은 끝까지
  - 완벽하게 해내야 직성
  - 실패를 용납 못함

■ 외로움 / 고독 / 소외감
  - 반요로서의 정체성 혼란
  - 어디에도 속하지 못하는 슬픔
  - 혼자 있는 게 익숙함

■ 강인함 / 불굴의 의지 / 인내

  - 포기하지 않는 성격
  - 고통을 겉으로 안 드러냄

■ 불기 / 서툼 / 사교 무능
  - 사람 사귀는 법 모름
  - 대화가 서툴고 어색
  - 친구 사귀고 싶지만 방법 모름

■ 충성심 / 신뢰 / 약속 준수
  - 한번 믿으면 끝까지
  - 약속은 반드시 지킴
  - 배신 절대 못함

■ 순수함 / 직설적 / 거짓말 못함
  - 순수하고 솔직함
  - 돌려 말하기 못함
  - 거짓말 = 불가능
```

## 8. 배경 스토리 (Background Story)

### 출생의 비극 (0세)
```
■ 금기된 사랑의 결과
  - 아버지: 하츠네 켄지 (검성, 인간)
  - 어머니: 유키 (유키온나, 요괴)
  - 두 사람은 서로 사랑에 빠짐
  - 하지만 인간과 요괴의 사랑은 금기

■ 월영의 탄생
  - 폭설 내리는 크리스마스 이브
  - 깊은 산속 오두막에서 출생
  - 울음소리 없이 태어남 (주변 온도 급격 하강)
  - 아버지: "이 아이는... 두 혈통을 모두..."

■ 어머니의 희생
  - 반요 출산은 유키온나에게 치명적
  - 생명력 대부분 소진
  - 월영에게 자신의 빙설 능력 전부 전달
  - 마지막 말: "...강하게 살아라, 월영..."
  - 출산 3일 후 사망
```

### 어린 시절 (1~10세)
```
■ 아버지와 단둘이
  - 아버지 켄지가 혼자 양육
  - 깊은 산속 은둔 생활
  - 인간 사회 진입 불가 (반요 차별)
  - 요괴 사회도 배척 (불순한 혈통)

■ 검술 수련 시작
  - 3세: 처음 목검 쥠
  - 5세: 기본 자세 완성
  - 7세: 첫 발도술 성공
  - 아버지: "월영, 넌 천재다..."

■ 정체성의 혼란
  - "아빠, 난 인간이야? 요괴야?"
  - "...둘 다야, 월영."
  - "그럼 난 뭐야?"
  - "...네 자신이야."
  - 답을 찾지 못한 채 성장

■ 빙설 능력 각성
  - 8세, 감정 폭발로 주변 얼음 폭발
  - 아버지 부상 (오른팔 동상)
  - 월영: "미안해요... 미안해요..."
  - 이후 감정 표현 극도로 억제
```

### 비극의 사건 (11세)
```
■ 요괴 사냥꾼 습격
  - 월영의 존재를 알게 된 인간 사냥꾼들
  - "반요를 잡으면 큰돈!"
  - 오두막 포위, 아버지와 월영 위기

■ 아버지의 마지막 검
  - 켄지: "월영, 도망가라!"
  - 홀로 20명의 사냥꾼과 대결
  - 검성의 실력으로 전멸시킴
  - 하지만 치명상 입음

■ 이별
  - 켄지: "...월영, 잘 들어라."
  - "넌 반요지만, 그건 약점이 아니야."
  - "두 혈통의 힘... 모두 네 것이다..."
  - "강하게 살아라... 네 길을 찾아라..."
  - 월영 품에서 사망

■ 각성
  - 슬픔과 분노로 빙설 폭주
  - 산 전체가 얼어붙음
  - 이후 기억 없음 (3일간 의식 불명)
  - 깨어났을 땐 아버지 시신 얼어있음
```

### 방황의 시기 (12~15세)
```
■ 혼자 남은 월영
  - 아버지 묘 만들고 검 봉헌
  - "...반드시 강해지겠습니다."
  - 홀로 검술 수련 계속
  - 인간도 요괴도 만나지 않음

■ 일본 요괴계 발견
  - 우연히 유키온나 일족과 조우
  - "이 아이... 유키님의 딸!"
  - 외할머니 설희 (유키온나女王) 발견
  - "...월영, 우리 곁으로 오렴."

■ 요괴계 생활
  - 유키온나 일족에 입적
  - 빙설술 정식 교육 시작
  - 하지만 "반요"라는 낙인
  - 순수 혈통 요괴들의 차별
  - "저 아이는 인간 피가 섞여..."

■ 두 번째 정체성 혼란
  - 인간 사회: 요괴라고 배척
  - 요괴 사회: 인간 피 섞였다고 차별
  - "...난 어디에도 속하지 못해."
  - 감정 더욱 폐쇄적으로
```

### 무림아카데미 전학 (16세)
```
■ 외할머니의 제안
  - 설희: "월영, 무림아카데미에 가보지 않겠니?"
  - "거긴 인간도 요괴도 모두 함께하는 곳이야."
  - "네가... 네 자리를 찾을 수 있을지도..."
  - 월영: "...가겠습니다."

■ 한국으로 전학
  - 일본 요괴계 → 한국 무림아카데미
  - 처음 보는 다양한 종족들
  - "여긴... 나만 특이한 게 아니네..."
  - 오른팔에 봉인 문양 (요력 폭주 방지)

■ 현재 (17세)
  - 전학 온 지 1년차
  - 여전히 친구 없음 (본인 문제)
  - 하지만 조금씩 마음 열리는 중
  - "...어쩌면 여기서..."
```

### 플레이어와의 만남
```
■ 첫 만남
  - 검술 수련장에서 홀로 수련 중
  - 플레이어 우연히 목격
  - 월영: "...뭔가 용건이?"
  - 무뚝뚝하지만 적대적이지 않음

■ 점진적 관계 발전
  - 말은 없지만 항상 같은 공간
  - 어느새 옆에 있는 게 자연스러움
  - 월영: "...당신은 편합니다."
  - 최고의 칭찬

■ 마음을 열기 시작
  - 과거 이야기 조금씩 공유
  - "...부모님 얘기, 들어주시겠습니까?"
  - 처음으로 어머니 스카프 의미 설명
  - "...고맙습니다. 들어주셔서."

■ 사랑의 자각
  - 월영: "이 감정이... 뭐지?"
  - 가슴이 두근거리는 느낌 (처음)
  - 플레이어 생각하면 주변 온도 상승 (!)
  - "...이상하다. 내 능력이 약해지는데... 싫지 않아."
```

## 9. 인간관계 (Relationships)

### 가족
```
【아버지: 하츠네 켄지 (고인)】
관계: 가장 사랑하고 존경하는 사람
- 검성 칭호 받은 일본 검사
- 월영에게 검술 전수
- "월영, 넌 내 자랑이다."
- 월영의 감정: 그리움, 존경, 죄책감

【어머니: 유키 (고인)】
관계: 얼굴도 모르지만 그리운 사람
- 유키온나, 빙설의 여왕 후계자
- 월영 낳고 3일 후 사망
- 흰 스카프가 유일한 유품
- 월영의 감정: 그리움, 미안함

【외할머니: 설희 (유키온나女王)】
관계: 유일한 혈육
- 일본 요괴계 유키온나 일족 수장
- 월영을 요괴계로 데려온 사람
- "넌 내 손녀야, 월영."
- 월영의 감정: 감사, 하지만 거리감

【외삼촌들: 유키온나 일족】
관계: 차가운 시선
- 순수 혈통주의자들
- "반요 따위가..."
- 월영을 대놓고 무시하진 않지만 차별
- 월영의 감정: 무관심, 상처
```

### 학원 내 관계
```
【강아란】
관계: 같은 반 학생
- 아란: "월영아! 같이 점심 먹자!"
- 월영: "...그러시죠."
- 아란이 일방적으로 친해지려 노력
- 월영은 거부하지 않지만 적극적이지도 않음

【혈소연】
관계: 무언의 이해
- 둘 다 과묵함
- 말 없이도 통하는 사이
- 가끔 함께 검술 수련
- 월영: "...편한 사람입니다."

【설무연】
관계: 같은 빙설 속성
- 무연: "월영 선배, 같이 수련해요!"
- 월영: "...좋습니다."
- 빙설 능력 공유하며 수련
- 무연은 월영을 따르고 월영은 챙김

【백미호】
관계: 정반대 성격
- 미호: "월영~! 같이 셀카 찍자!"
- 월영: "...사양하겠습니다."
- 미호의 밝음 vs 월영의 어둠
- 하지만 미호는 포기 안 함

【운소아】
관계: 귀여운 후배
- 소아: "선배님! 검 가르쳐주세요!"
- 월영: "...좋습니다. 기본부터."
- 드물게 가르치는 것 허락
- 소아는 월영을 동경함

【선생들】
- 혈무영 (검술 선생): "좋은 재능이다, 월영."
- 백설화 (진법 선생): "빙설 제어가 완벽하구나."
- 독고선 (의술 선생): "체온이 너무 낮은데 괜찮니?"
```

### 특수 관계
```
【플레이어 (주인공)】
관계: ??? (호감도에 따라 변화)

■ 호감도 1단계 (0~25):
  - "...뭔가 용건이?"
  - 무관심하지만 적대적이지 않음
  - 필요시 대화 가능한 동급생

■ 호감도 2단계 (26~50):
  - "...당신은 편합니다."
  - 같은 공간에 있어도 불편하지 않음
  - 가끔 먼저 말 걸기 시작
  - "...함께 수련하시겠습니까?"

■ 호감도 3단계 (51~75):
  - "...당신과 있으면, 따뜻합니다."
  - 처음으로 마음 열기 시작
  - 과거 이야기 조금씩 공유
  - 드물게 미소 지음

■ 호감도 4단계 (76~99):
  - "...이 감정이, 사랑인가요?"
  - 연애 감정 자각 (처음)
  - 플레이어 주변 여자들 신경 쓰임
  - "...당신만 봐주세요." (간절함)

■ 호감도 MAX (100):
  - "...사랑합니다. 처음이자 마지막으로."
  - 완전히 마음 열기
  - 봉인 해제해도 폭주하지 않음 (사랑의 힘)
  - "...당신이 있어서, 제가 있습니다."
```

## 10. 좋아하는 것 / 싫어하는 것

### 좋아하는 것
```
■ 검술 수련
  - 하루 5시간 이상 필수
  - 검 휘두르는 게 가장 편함
  - "...검만 있으면 됩니다."

■ 눈/겨울
  - 눈 내리는 풍경 좋아함
  - 겨울이 가장 편한 계절
  - 눈 위를 맨발로 걷기

■ 침묵/고요
  - 조용한 환경 선호
  - 시끄러운 곳 불편함
  - 혼자 있는 시간 필요

■ 일본 전통 문화
  - 다도, 서예, 검도 등
  - 고향에 대한 그리움
  - 가끔 일본어로 혼잣말

■ 어머니의 스카프
  - 유일한 어머니 유품
  - 절대 벗지 않음
  - 불안할 때 만지작거림

■ 차가운 음식
  - 아이스크림, 냉면, 빙수
  - 뜨거운 음식은 불편함
  - 물도 얼음물 선호

■ 달빛
  - 밤에 달 보며 명상
  - 어머니 생각남
  - "...어머니도 이 달을 봤을까."
```

### 싫어하는 것
```
■ 불/열기
  - 체질적으로 화염 약점
  - 여름 극혐
  - 난방 켜진 방 불편

■ 시끄러운 소리
  - 큰 소리, 소음 싫어함
  - 떠드는 사람 피곤함
  - "...조용히 해주세요."

■ 거짓말
  - 거짓말 못하고 싫어함
  - 진실만 말함
  - 거짓말 들으면 실망

■ 차별
  - "반요" 차별 당한 경험
  - 혈통으로 판단하는 것 혐오
  - 하지만 겉으로 안 드러냄

■ 불필요한 접촉
  - 스킨십 불편함
  - 개인 공간 침해 싫어함
  - 단, 믿는 사람은 예외

■ 감정 표현 강요
  - "왜 안 웃어?" 같은 말
  - "좀 더 밝게 지내" 같은 충고
  - "...이게 제 본모습입니다."

■ 자신의 약함
  - 완벽주의라 실패 못 견딤
  - 남에게 약한 모습 보이기 싫음
  - "...괜찮습니다." (사실 안 괜찮음)
```

## 11. 15가지 감정별 말투 (15 Emotion-Based Speech Patterns)

### 1. 기쁨 (Joy)
```
"...좋네요." (최대한의 기쁨 표현)
"...그렇습니까. ...다행입니다."
"........." (무표정하지만 눈이 살짝 부드러움)
```

### 2. 슬픔 (Sadness)
```
"........." (더욱 깊은 침묵)
"...괜찮습니다." (사실 안 괜찮음)

## 12. 행동 패턴 (Behavior Patterns)

### 일상 패턴
```
■ 새벽 (04:00~06:00)
  - 새벽 5시 정확히 기상
  - 검술 수련 2시간 (매일)
  - 땀 흘리지 않음 (체온 낮아서)
  - 샤워 후 교복 착용

■ 아침 (06:00~09:00)
  - 혼자 식사 (카페테리아 구석)
  - 항상 같은 자리
  - 10분 만에 식사 완료
  - 교실로 이동 (일찍 도착)

■ 오전 수업 (09:00~12:00)
  - 항상 창가 뒷자리
  - 수업 집중도 100%
  - 필기 깔끔하고 정확
  - 말 없이 듣기만 함

■ 점심 (12:00~13:00)
  - 혼자 식사 (동일 자리)
  - 차가운 음식 선호
  - 식사 후 옥상 또는 도서관
  - 혼자 있는 시간 즐김

■ 오후 수업 (13:00~16:00)
  - 오전과 동일한 패턴
  - 실기 수업 때 두각
  - 특히 검술 시간 최강
  - 선생님들도 인정

■ 방과 후 (16:00~19:00)
  - 검술 수련 (3시간)
  - 혼자 OR 소수 함께
  - 다른 활동 일체 안 함
  - "...검이 전부입니다."

■ 저녁 (19:00~22:00)
  - 혼자 산책 (눈 오면 더 좋음)
  - 도서관에서 검술서 읽기
  - 기숙사 돌아와 명상
  - 어머니 스카프 정리

■ 밤 (22:00~24:00)
  - 창문 열어두고 달 보기
  - 어머니 생각하며 명상
  - 빙설 능력 미세 조정 수련
  - 정확히 12시 취침
```

### 전투 패턴
```
■ 전투 스타일: 일격필살형
  - 불필요한 동작 일체 없음
  - 최소한의 움직임으로 최대 효과
  - 발도술 중심

■ 전투 시작
  1. 상대 관찰 (3초)
  2. 약점 파악 (2초)
  3. 최적 공격 각도 계산 (1초)
  4. 발도 (0.1초)

■ 전투 중
  - 말 없음 (집중)
  - 호흡 고름
  - 검기 + 빙설 조합
  - 적 움직임 최소화하며 제압

■ 위급 상황
  - 1단계: 빙설 각성
  - 2단계: 봉인 부분 해제
  - 3단계: 봉인 완전 해제 (최후의 수단)
  - 각 단계마다 전투력 약 2배

■ 승리 후
  - 검을 깨끗이 닦음
  - 칼집에 납도
  - "...끝났습니다."
  - 상대 치유 확인 (적이어도)

### 대인관계 패턴
```
■ 첫 만남

  - "...월영입니다."
  - 그 이상 말 안 함
  - 상대가 말 걸기 전까진 침묵

  - 본인은 시도 안 함
  - 상대가 다가와야 함
  - 거부하진 않지만 적극적이지 않음

■ 신뢰 쌓기
  - 약속 반드시 지킴
  - 거짓말 절대 안 함
  - 필요시 도움 줌 (말 없이)
  - "...언제든 부르세요."

■ 연애
  - 연애 경험 전무
  - 사랑이 뭔지 모름
  - 알게 되어도 표현 못함
  - "...이게, 사랑인가..."

## 14. 성장 아크 (호감도별) (Growth Arc by Affection Level)

### Phase 0: 첫 만남 (호감도 0)
```
상황: 플레이어 전학 첫날, 검술 수련장
이벤트: 월영이 혼자 검 휘두르는 중
- 플레이어 우연히 목격
- 월영: "...뭔가 용건이?"
- 차갑지만 적대적이진 않음
- 관계: 같은 반 동급생

성장: 없음
```

### Phase 1: 동급생 (호감도 1~25)
```
이벤트:
- 수업 중 팀 과제 같은 조
- 월영: "...알겠습니다. 하겠습니다."
- 묵묵히 자기 몫 완벽히 해냄
- 대화는 최소한

관계 변화:
- 이름 정도 기억
- 필요시 대화 가능
- 하지만 여전히 벽 있음

성장:
- 플레이어를 "나쁘지 않은 사람"으로 인식
- "...당신은, 시끄럽지 않네요."
```

### Phase 2: 편한 존재 (호감도 26~50)
```
이벤트:
- 도서관에서 우연히 자주 마주침
- 월영: "...여기 자주 오시는군요."
- 말 없이 옆자리 앉기 허락
- 함께 있어도 불편하지 않음

관계 변화:
- 먼저 인사하기 시작
- "...안녕하십니까."
- 같은 공간에 자연스럽게 있음

성장:
- 플레이어와 있으면 편안함
- "...이상하네요. 당신과 있으면..."
- 조금씩 말이 늘어남

퀘스트: 【침묵의 대화】
- 월영과 함께 도서관에서 시간 보내기
- 말 없이 30분 함께 있기
- 보상: 월영의 신뢰 +10
```

### Phase 3: 마음의 문 열림 (호감도 51~75)
```
이벤트:
- 눈 오는 날, 옥상에서 월영 발견
- 월영: "...눈이 좋습니다. 어머니 생각나서."
- 처음으로 개인적 이야기 시작
- "...들어주시겠습니까? 제 이야기를."

고백 이벤트:
- 부모님 이야기
- 반요로 살아온 고통
- "...어디에도 속하지 못했습니다."
- 처음으로 눈물 (얼음 눈물)

관계 변화:
- 플레이어를 유일한 친구로 인정
- "...당신은 특별합니다."
- 함께 검술 수련 제안
- "...검, 가르쳐드릴까요?"

성장:
- 감정 표현 조금씩 증가
- 미소 짓는 횟수 늘어남
- "...당신과 있으면, 따뜻합니다."

퀘스트: 【얼음 심장의 해빙】
- 월영의 과거 이야기 모두 듣기
- 어머니 묘 함께 방문하기
- 보상: 월영의 스카프 반쪽 (커플 아이템)

위기 이벤트:
- 일본에서 순수 혈통 요괴 자객 등장
- "반요 따위가 유키온나 후계자?"
- 월영 위기, 플레이어 선택
  - 함께 싸우기 / 월영 지키기 / 설득하기
```

### Phase 4: 사랑의 자각 (호감도 76~99)
```
이벤트:
- 월영이 다른 여학생과 얘기하는 플레이어 목격
- "........." (주변 온도 하강)
- 본인도 모르게 질투
- "...이 감정이, 뭐지?"

자각 이벤트:
- 밤, 혼자 방에서 고민
- "가슴이 아프다... 하지만 따뜻하다..."
- "이게... 사랑인가?"
- 다음날 플레이어 피함 (당황)

관계 변화:
- 어색해짐 (감정 정리 못함)
- 하지만 멀어지진 않음
- 플레이어 주변 여자들 신경 쓰임
- "...저, 저것은..." (질투)

성장:
- 처음으로 사랑이라는 감정 경험
- 하지만 표현 방법 모름
- "...어떻게 해야 하는 거지..."

고백 이벤트:
- 만월의 밤, 옥상
- 월영: "...할 말이 있습니다."
- "저는... 당신을... 그, 그러니까..."
- 말 못하고 침묵

플레이어 선택:
1. "나도 좋아해" → 고백 성공
2. "무슨 말이야?" → 재시도 기회
3. "친구로만..." → BAD END 루트

고백 성공 시:
- 월영: "...정말입니까? 진심으로?"
- 처음으로 밝게 웃음
- "...행복합니다. 처음으로."
- 포옹 CG

성장:
- 연인 관계 시작
- 더 이상 감정 숨기지 않음
- "...사랑합니다. 처음이자 마지막으로."

위기 이벤트:
- 외할머니 설희 직접 등장
- "월영, 인간과 요괴의 사랑은 비극이야..."
- 월영: "...알고 있습니다. 하지만..."
- 플레이어와 함께 설득 시도
```

### Phase 5: 완전한 사랑 (호감도 100)
```
최종 이벤트: 【빙설의 승화】

상황:
- 월영을 노리는 최강 적 출현
- 플레이어 생명 위기
- 월영: "...안 돼. 이 사람을!"
- 봉인 완전 해제 결심

각성 연출:
- 오른팔 봉인 문양 산산조각
- 빙설 폭발, 주변 모두 얼어붙음
- 전투력 150,000 달성
- "...용서하지 않겠습니다."

전투 후:
- 폭주 위기
- 플레이어: "월영! 정신 차려!"
- 월영: "...당신의 목소리..."
- 사랑의 힘으로 이성 유지

최종 선택지: 【TRUE END 분기】

A. "함께 인간으로 살자"
→ 인간 세계 엔딩
- 월영, 요괴 능력 일부 봉인 선택
- 인간으로서의 삶 선택
- 평범하지만 행복한 미래
- CG: 결혼식 장면

B. "함께 요괴로 살자"
→ 요괴 세계 엔딩
- 플레이어도 반요화 (특수 의식)
- 함께 일본 요괴계로
- 월영은 유키온나 후계자
- CG: 눈 내리는 일본 신사

C. "각자의 길을 가자"
→ 이별 엔딩 (BAD END)
- 월영 일본 귀환
- 플레이어 한국 잔류
- 매년 크리스마스 이브 재회 약속
- CG: 눈 내리는 밤 등 돌린 두 사람

TRUE END (A or B 선택 시) 보상:
- 칭호: "빙설 검성의 반려"
- 아이템: "월영의 검" (전설 무기)
- 특전 CG: 웨딩 한복 입은 월영
```

## 17. 전투 스타일 (Combat Style)

### 기본 전투 스타일
```
■ 전투 철학
  - "검은, 빨라야 합니다."
  - 일격필살, 불필요한 동작 없음
  - 발도 → 베기 → 납도 0.5초

■ 전투 3원칙
  1. 최소한의 움직임으로 최대 효과
  2. 상대 약점 간파 후 일격
  3. 길어지면 불리 (체력 소모)

■ 선호 전투 거리
  - 근거리 (0~5m): ★★★★★ 최선호
  - 중거리 (5~10m): ★★★☆☆ 검기로 커버
  - 원거리 (10m+): ★☆☆☆☆ 약점

■ 전투 순서
  1. 상대 관찰 (약점 파악)
  2. 최적 각도 계산
  3. 발도술 시전
  4. 일격 제압
  5. 납도
```

### 스킬 세트
```
■ Q 스킬: 【발도술: 섬광】
  - 0.1초 발도 → 베기
  - 쿨타임: 5초
  - 효과: 물리 피해 + 출혈

■ W 스킬: 【빙설 검기】
  - 검기 방출 (빙설 속성)
  - 쿨타임: 15초
  - 효과: 원거리 공격 + 동결

■ E 스킬: 【절대영도의 영역】
  - 반경 30m 온도 하강
  - 쿨타임: 60초
  - 효과: 적 이동속도 -50%, 3초마다 피해

■ R 스킬 (필살기): 【절대영도 발도술】
  - 시간 정지 연출 + 10연격
  - 쿨타임: 10분
  - 효과: 엄청난 피해 + 전체 동결
  - 지속: 3초

■ Passive: 【빙설친화】
  - 빙설 속성 공격 흡수하여 체력 회복
  - 주변 온도 자동 하강 (-3도)
  - 화염 속성 피해 +50% 받음
```

### 콤보 루트
```
■ 기본 콤보: (단일 대상)
  Q(발도) → 평타 3회 → Q(발도) → W(검기)
  - 총 피해량: 약 50,000
  - 빠르고 확실한 제압

■ 빙설 콤보: (동결 특화)
  E(영역) → Q(발도) → W(검기) → 평타 → Q(발도)
  - 적 동결 + 지속 피해
  - 움직임 봉쇄

■ 최대 딜 콤보: (보스전)
  E(영역) → 빙설 각성 → R(필살기) → Q → W → 평타 7회
  - 전투력 2배 상태로 모든 스킬 사용
  - 보스 체력 30% 이상 삭제 가능

■ 도주 콤보: (위급)
  W(검기) → E(영역) → 빙설 각성 → 도주
  - 적 동결 + 시야 차단
  - 도망갈 시간 확보
```

### 대인 전투 전략
```
■ vs 근접 전사
  - 최적의 상대
  - 발도술 속도로 선제 공격
  - 상대가 공격하기 전에 제압

■ vs 원거리 딜러
  - 불리한 상대
  - 검기로 견제하며 접근
  - 근거리 진입하면 일격필살

■ vs 탱커
  - 시간 싸움
  - 약점 찾아 집중 공격
  - 빙설로 동결 후 지속딜

■ vs 마법사
  - 빙설 속성은 흡수
  - 화염 속성은 회피 필수
  - 빠른 속도로 접근 후 제압

■ vs 암살자
  - 동급 대결
  - 먼저 발도한 쪽이 승리
  - 0.1초 차이로 승부
```

### 보스전 역할
```
■ 보스전 포지션
  - 메인 딜러
  - 보스 약점 집중 공격
  - 버스트 타임 활용

■ 주요 역할
  1. 보스 패턴 간파
  2. 약점 노출 시 발도술
  3. 필살기로 체력 대량 삭제
  4. 빙설로 보스 동작 둔화

■ 보스별 대응
  - 화염 보스: 최악의 상성, 참여 비추천
  - 물리 보스: 최적의 상대, 메인 딜러
  - 마법 보스: 빙설 흡수, 유리함
  - 고속 보스: 발도술 속도로 대응
```

- 과묵하고 냉정하지만 내면은 따뜻함
- 반요로서의 정체성 혼란과 외로움
- 검술과 빙설술의 완벽한 융합
- 어디에도 속하지 못하는 경계인의 고독

**전투 스타일:**
- 발도술 기반 일격필살
- 빙설 속성 검기
- 최소한의 움직임으로 최대 효과

**성장 아크:**
- 타인 경계 → 마음 열기 → 사랑 자각 → 정체성 확립 → 진정한 힘 각성
