# 장법 계열 스킬

## 📋 개요

**계열**: 장법 (掌法)
**주 무기**: 손바닥
**특징**: 다양한 응용, 내력 전달
**대표 문파**: 소림사, 개방, 무당파

---

## ⭐ 등급 체계

### SSS급 - 신화 장법
**위력**: 산맥을 밀어냄

### SS급 - 전설 장법
**위력**: 산을 밀어냄

### S급 - 절정 장법
**위력**: 거대 바위 날림

### A급 - 고급 장법
**위력**: 나무 뿌리뽑기

### B급 - 중급 장법
**위력**: 벽돌 날리기

## 👋 SSS급 장법

### 1. 천지대이동 (天地大移動)
**등급**: SSS
**소속**: 전설
**습득 조건**: 공간 이해 + 화경 절정

**효과**:
- 공간 자체를 밀어냄
- 범위: 반경 10km
- 대상 강제 이동
- 지형 변화

**기술 구성**:
```
1초: 천이장 - 하늘을 밀음
2초: 지이장 - 땅을 밀음
3초: 천지역전 - 천지를 뒤집음
```

**제한**:
- 1개월 1회
- 생명력 90% 소모

---

### 2. 불멸화천장 (不滅化天掌)
**등급**: SSS
**소속**: 고대 비급
**습득 조건**: 불의 극의 + 화경 절정

**효과**:

- 온도: 10만도
- 모든 것 소멸

**특징**:
- 손바닥이 태양처럼 빛남
- 범위: 반경 5km
- 사용 후 1년 회복 필요

## 🎯 장법 조합 시스템

### 장법 + 장법
```
화염천장 + 빙혼백골장 = 빙화무쌍장 (SS-)
- 화염 + 냉기
- 온도차 극대화
```

### 장법 + 내공
```
항룡유회장 + 구양신공 = 양룡천장 (SSS-)
- 용 + 절대 양기
- 최강 단일 타격
```

### 장법 + 권법
```
대금강장 + 대라한권 = 나한금강법 (SS)
- 방어 + 공격
- 완벽한 조화
```

## 💡 특수 장법 효과

### 장력 (掌力)
- 조건: 장법 기본
- 효과: 손바닥에서 힘 방출
- 사정거리: 1m

### 장강 (掌罡)
- 조건: 화경 초기
- 효과: 장력 실체화
- 사정거리: 10m

### 장기 (掌氣)
- 조건: 화경 중기
- 효과: 장력 파동화
- 사정거리: 50m

### 장의 (掌意)
- 조건: 장법 극의
- 효과: 손바닥 없이 장력
- 사정거리: 100m

## 🔄 장법 진화 시스템

### 기본 → 고급
```
기본 장법 (B)
→ 연환장 (B+)
→ 강력장 (A)
→ 항룡십팔장 (A)
→ 항룡유회장 (SS)
→ 천지대이동 (SSS)
```

### 속성 부여
```
항룡십팔장 (A)
+ 화염 = 화룡장 (S)
+ 빙설 = 빙룡장 (S)
+ 뇌전 = 뇌룡장 (S)
```

## 🌀 장법 vs 권법

### 장법 장점
- 면 타격 (넓은 접촉면)
- 내력 전달 우수
- 방어 전환 쉬움
- 다양한 응용

### 권법 장점
- 점 타격 (집중력)
- 순수 파괴력
- 단순하고 강력

### 선택 기준
```
장법 선택:
- 내공 중시
- 기술 중시
- 유연한 전투

권법 선택:
- 힘 중시
- 단순함 선호
- 직선적 전투
```
