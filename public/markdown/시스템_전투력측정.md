## 💯 전투력 구성

### 종합 전투력 공식
```
총 전투력 = (내공 × 0.4) + (무공 숙련도 × 0.3) + (신체 능력 × 0.2) + (실전 경험 × 0.1)
```

### 세부 항목

#### 1. 내공 (40%)
```
측정 기준:
- 내공 순도
- 내공 용량
- 회복 속도
- 지속력

수치 범위:
- 일반인: 0-100
- 입문: 100-1,000
- 초보 무림인: 1,000-5,000
- 중급 무림인: 5,000-10,000
- 고급 무림인: 10,000-30,000
- 고수: 30,000-50,000
- 절정고수: 50,000-80,000
- 초절정: 80,000-100,000
- 화경: 100,000+
```

#### 2. 무공 숙련도 (30%)
```
측정 기준:
- 보유 무공 수
- 무공 등급
- 숙련도
- 응용력

등급별 점수:
- D급 무공: 100점
- C급 무공: 300점
- B급 무공: 1,000점
- A급 무공: 3,000점
- S급 무공: 10,000점
- SS급 무공: 30,000점
- SSS급 무공: 100,000점

숙련도 배율:
- 입문 (10%): × 0.1
- 초급 (30%): × 0.3
- 중급 (50%): × 0.5
- 고급 (70%): × 0.7
- 달인 (90%): × 0.9
- 극의 (100%): × 1.0
- 초월 (120%): × 1.2
```

#### 3. 신체 능력 (20%)
```
측정 항목:
- 근력
- 민첩성
- 체력
- 반응속도
- 유연성

특수 체질 보너스:
- 일반 체질: × 1.0
- 우수 체질: × 1.2
- 희귀 체질: × 1.5
- 전설 체질: × 2.0
- 신화 체질: × 3.0
```

#### 4. 실전 경험 (10%)
```

- 대련 횟수
- 승률
- 강적 격파
```
