# 대장장이 (鍛造師) 직업

## 📋 개요

**직업명**: 대장장이 (鍛造師)
**주 특기**: 무기/방어구 제작
**특징**: 창조, 제작, 수리
**대표 인물**: 신병장인, 천하제일공, 무기왕

---

## ⭐ 직급 체계

### 전설
- **신장** (神匠) - 신의 장인
- **천공** (天工) - 하늘의 장인
- **대장인** (大匠人) - 위대한 장인

### 고급
- **명장** (名匠) - 이름난 장인
- **숙련공** (熟練工) - 숙련된 기술자
- **대장장이** (鍛造師) - 제작자

### 중급
- **견습공** - 수련 중
- **초보공** - 입문

---

## 💪 직업 특성

### 장점
1. **높은 수익**: 명품 무기 고가
2. **안정성**: 항상 수요 있음
3. **존경받음**: 기술자 대우
4. **창조의 기쁨**: 작품 제작
5. **평생 직업**: 나이 들어도 가능

### 단점
1. **전투 약함**: 직접 싸우기 어려움
2. **육체 노동**: 힘든 작업
3. **긴 수련**: 숙련 오래 걸림
4. **초기 비용**: 재료비, 장비비
5. **화상 위험**: 불 다룸

## 🔨 전문 분야

### 1. 검 제작자
**특화**: 검 (劍)

**특징**:
- 섬세한 작업
- 균형 중요
- 예술성
- 고난도

**제작 가능**:
- 일반검 (B급)
- 명검 (A급)
- 보검 (S급)
- 신검 (SS급)
- 천검 (SSS급)

**제작 기간**:
- B급: 7일
- A급: 30일
- S급: 6개월
- SS급: 2년
- SSS급: 5년+

**수익**: 극상

## 🎪 코믹 요소

### 대장장이의 일상
```
아침: "오늘도 두드린다"
→ 망치질 1만 번

점심: "팔 아파..."
→ 계속 두드림

저녁: "언제 끝나지?"
→ 여전히 두드림

밤: "드디어 완성!"
→ 균형 안 맞음
→ "다시..."
```

### 대장장이의 고민
1. **화상**
   - "뜨거워!!"
   - 매일 화상
   - "직업병이야..."

2. **소음**
   - 땡땡땡 (하루종일)
   - 이웃: "시끄러워!!"
   - "...미안"

3. **완벽주의**
   - "1mm가 안 맞아"
   - → 다시 제작
   - 의뢰인: "충분한데..."
   - "안 돼!!"
