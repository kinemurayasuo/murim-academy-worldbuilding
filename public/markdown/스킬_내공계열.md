# 내공 계열 스킬

## 📋 개요

**계열**: 내공 (內功)
**핵심**: 진기 수련 및 운용
**특징**: 모든 무공의 기초, 지속 성장
**중요도**: 최상급 (내공 = 무공의 뿌리)

---

## ⭐ 등급 체계

### SSS급 - 신화 내공
**수련 난이도**: 천재 중 천재
**효과**: 세계 법칙 수준

### SS급 - 전설 내공
**수련 난이도**: 극상
**효과**: 산천을 움직임

### S급 - 절정 내공
**수련 난이도**: 상
**효과**: 강 물줄기 바꿈

### A급 - 고급 내공
**수련 난이도**: 중
**효과**: 바위 분쇄

### B급 - 중급 내공

**수련 난이도**: 입문

## 🌟 SSS급 내공

### 1. 선천기공 (先天氣功)
**등급**: SSS
**소속**: 전설
**수련 조건**: 선천적 재능 + 화경 절정

**효과**:
- 진기 무한 생성
- 자동 회복 (100%/초)
- 모든 속성 사용 가능
- 수명 연장 (+500년)

**특징**:
```
단계:
1단: 선천의 문 - 진기 생성 10배
2단: 선천의 길 - 진기 질 변화
3단: 선천의 완성 - 진기 = 법칙
```

**현재 사용자**: 전무 (전설상으로만 존재)

---

### 2. 혼돈진기 (混沌眞氣)
**등급**: SSS
**소속**: 고대 비급
**수련 조건**: 음양 + 오행 완벽 이해

**효과**:
- 모든 내공 흡수 가능
- 진기 형태 자유 변환
- 마공도 정공으로 변환
- 진기 폭주 무효

**위험성**:
- 수련 실패 시 100% 사망
- 진기 역류 위험
- 정신 붕괴 가능성

---

### 3. 불멸진기 (不滅眞氣)
**등급**: SSS
**소속**: 불로불사 비급
**수련 조건**: 생사 이해 + 화경 절정

## 🎯 내공 융합 시스템

### 음양 융합
```
구양신공 + 구음진경 = 음양무극공 (SSS)
- 음양 완벽 조화
- 모든 속성 무효화
- 진기 무한 순환
```

### 오행 융합
```
화염진기 + 빙설진기 + 뇌전진기 + 토행진기 + 목행진기 = 오행진기 (SS+)
- 모든 속성 사용
- 상성 무시
```

### 정마 융합
```
소림내공 + 혈마공 = 정마양면 (S+)
- 정공 + 마공
- 위험하지만 강력
```

## 💡 특수 내공 상태

### 진기 폭주
- 원인: 과도한 수련 or 진기 충돌
- 증상: 진기 제어 불가
- 위험: 경맥 파열, 사망
- 해결: 고수의 진기 조정

### 주화입마 (走火入魔)
- 원인: 잘못된 수련법
- 증상: 정신 착란
- 위험: 영구 정신 손상
- 해결: 정신 회복 비급

### 경맥 확장
- 조건: 올바른 수련
- 효과: 진기 총량 증가
- 방법: 단계적 수련

### 진기 역류
- 원인: 강한 충격
- 증상: 내상
- 위험: 경맥 손상
- 해결: 치료 내공

## 🔄 내공 전환 시스템

### 정공 → 마공
- 가능: 위험 높음
- 효과: 즉시 강해짐
- 대가: 이성 상실

### 마공 → 정공
- 가능: 극도로 어려움
- 효과: 정화
- 조건: 고승의 도움

### 속성 변환
- 화 → 빙: 가능 (10년 소요)
- 빙 → 화: 가능 (10년 소요)
- 뇌 → 기타: 가능 (5년 소요)
