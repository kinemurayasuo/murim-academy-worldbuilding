# 의술 및 독술 계열

## 📋 개요

**계열**: 의술 (醫術) & 독술 (毒術)
**핵심**: 치료 vs 살상
**특징**: 생명 조작의 양면
**대표 문파**: 의왕곡 (의술), 당가 (독술)

---

## ⭐ 등급 체계

### SSS급 - 신의/독왕
**의술**: 죽은 자 살림
**독술**: 불치독 제조

### SS급 - 명의/독성
**의술**: 불치병 치료
**독술**: 맹독 제조

### S급 - 고수/독사
**의술**: 중병 치료
**독술**: 치명독 제조

### A급 - 의사/독객
**의술**: 일반 치료
**독술**: 독 제조

### B급 - 약사/독초
**의술**: 기본 치료
**독술**: 약독 제조

## 💊 SSS급 의술

### 1. 회생술 (回生術)
**등급**: SSS
**소속**: 전설
**습득 조건**: 의술 극의 + 생사 이해

**효과**:
- 죽은 지 1시간 이내 소생
- 파괴된 장기 재생
- 수명 연장
- 불치병 치료

**치료 과정**:
```
1단계: 영혼 고정 (떠나기 전)
2단계: 심장 재가동
3단계: 뇌 재생
4단계: 장기 복구
5단계: 생명력 주입
```

**제한**:
- 1년 1회
- 시술자 수명 10년 소모
- 머리 파괴 시 불가능

---

### 2. 천의신침 (天醫神針)

**소속**: 의왕곡
**습득 조건**: 침술 극의 + 화경 절정

- 모든 질병 치료
- 경지 상승 도움

**108침**:
```

37-72침: 장기 치료
73-108침: 경지 상승
```

**특수 능력**:
- 침으로 독 제거
- 내상 즉시 치료
- 주화입마 해결

## 🎯 의술 + 독술 융합

### 독의 쌍절 (毒醫雙絶)
```
의술 SSS + 독술 SSS = 생사장악 (초월)
- 생사 완벽 조작
- 죽이고 살리기 자유
- 독으로 치료, 약으로 독살
```

### 화타재세 (華佗再世)
```
의술 극의 + 침술 극의 = 신의 (SSS)
- 죽은 자도 살림
- 모든 병 치료
```

### 독왕 (毒王)
```
독술 극의 + 독 체질 = 살아있는 독 (SSS)
- 존재 자체가 독
- 접촉 시 사망
```
