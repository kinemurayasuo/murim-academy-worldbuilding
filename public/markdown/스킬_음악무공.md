# 음악 무공 계열

## 📋 개요

**계열**: 음공 (音功)
**주 무기**: 악기 및 음파
**특징**: 광역 공격, 정신 공격, 보조 효과
**대표 문파**: 음악궁, 소림사 음공원

---

## ⭐ 등급 체계

### SSS급 - 신화 음공
**효과**: 천지를 울림

### SS급 - 전설 음공
**효과**: 산천을 울림

### S급 - 절정 음공
**효과**: 강을 울림

### A급 - 고급 음공
**효과**: 숲을 울림

**효과**: 방을 울림

## 🎵 SSS급 음공

### 1. 천마광음곡 (天魔狂音曲)
**등급**: SSS
**소속**: 천마신교
**습득 조건**: 천마공 + 음공 극의

**효과**:
- 세상을 뒤흔드는 마음
- 범위: 반경 10km
- 정신 붕괴 유발
- 광기 전염

**7악장 구성**:
```
1악장: 서곡 - 불안 조성
2악장: 광란 - 이성 상실
3악장: 절망 - 의지 붕괴
4악장: 환각 - 현실 왜곡
5악장: 공포 - 두려움 극대
6악장: 파멸 - 정신 파괴
7악장: 종말 - 영혼 소멸
```

**부작용**:
- 연주자도 영향
- 이성 점차 상실
- 장기 연주 시 마화

---

### 2. 천상선율 (天上仙律)
**등급**: SSS
**소속**: 전설
**습득 조건**: 음공 극의 + 선경 진입

**효과**:

- 모든 부상 치유
- 정신 회복
- 수명 연장

**9악장 구성**:
```
1악장: 여명 - 희망의 시작
2악장: 치유 - 상처 회복
3악장: 정화 - 독 및 저주 제거
4악장: 재생 - 절단 부위 재생
5악장: 각성 - 잠재력 해방
6악장: 승화 - 경지 상승
7악장: 회춘 - 나이 역행
8악장: 불사 - 생명 연장
9악장: 신선 - 선계 진입
```

**제한**:
- 1년에 1회
- 연주 시간: 7일 7야

## 🎯 음공 조합 시스템

### 음공 + 음공
```
천룡음 + 비파살 = 용음비파 (SSS-)
- 용의 울음 + 비파 살상
- 회피 불가 공격
```

### 음공 + 무공
```
칠현무형검 + 화산매화검 = 검음합일 (SS)
- 검 + 음파
- 보이지 않는 매화검
```

### 음공 + 내공
```
천상선율 + 선천기공 = 선천치유음 (SSS)
- 완벽한 치유
- 죽음 직전도 회복
```

## 💡 음공 특수 효과

### 공명 (共鳴)
- 조건: 같은 음공 사용자 2명+
- 효과: 위력 2배+ 증폭

### 불협화음 (不協和音)
- 조건: 다른 음공 충돌
- 효과: 양쪽 모두 약화

### 완벽한 조화 (完璧調和)
- 조건: 음공 극의 + 조화
- 효과: 위력 10배

### 침묵의 소리 (沈默之聲)
- 조건: 음공 최고 경지
- 효과: 소리 없이 음파

## 🏆 음공 랭킹 (학원 내)

1. **이름 미정** - 비파살 (SS급)
2. **음악 특기생** - 칠현무형검 (S급)
3. **합창단장** - 유성곡 (A급) 완벽

1. **음악치료사** - 안혼곡 (A급) + 재능
2. **퉁소 연주자** - 옥소음공 (S급) 치유 특화

## 💫 특수 음공 상황

### 합주 (合奏)
- 조건: 2명 이상
- 효과: 개인 연주 × 인원수
- 난이도: 호흡 일치 필요

### 대편성 (大編成)
- 조건: 10명 이상 오케스트라
- 효과: 기적의 음악
- 가능: 군대급 파괴력 or 치유

### 독주 (獨奏)
- 조건: 1명
- 효과: 개인 실력 집중
- 특징: 섬세함 극대

### 즉흥 연주 (卽興演奏)
- 조건: 음악 감각 극상
- 효과: 상황 맞춤 음악
- 난이도: 극상

## 🌀 음공 vs 다른 무공

### 음공 장점
- 광역 공격
- 정신 공격 (방어 어려움)
- 치유 및 보조 가능
- 예술성

### 음공 단점
- 악기 필요 (보통)
- 귀막으면 약화
- 수련 오래 걸림
- 재능 필요

### 대응법
```
음공 상대 시:
1. 귀 막기 (50% 효과)
2. 진기로 고막 보호 (70% 효과)
3. 더 큰 소리로 덮기 (음공 대 음공)
4. 침묵 결계 (음파 차단)
```
