# 경공 계열 스킬

## 📋 개요

**계열**: 경공 (輕功)
**핵심**: 신법, 보법, 이동술
**특징**: 속도, 회피, 기동성
**중요도**: 생존의 핵심

## 🎯 경공 조합 시스템

### 경공 + 경공
```
신행백변 + 제비삼천도 = 신행제비보 (SS+)
- 잔상 + 민첩함
- 완벽한 회피
```

### 경공 + 무공
```
삼천뇌동 + 뇌전검 = 뇌신섬광 (SSS-)
- 속도 + 공격
- 예측 불가 일격
```

### 경공 + 내공
```
시공신법 + 선천기공 = 시공선천보 (SSS)
- 시간 + 무한 진기
- 영원한 가속
```

## 🔄 경공 진화 시스템

### 기본 → 고급
```
기본 경공 (B)
→ 조보 (B+)
→ 매복추일보 (A)
→ 제비삼천도 (S)
→ 신행백변 (SS)
→ 순보천리 (SSS)
```

### 속성 부여
```
제비삼천도 (S)
+ 화염 = 화염제비보 (S+)
+ 빙설 = 빙설제비보 (S+)
+ 뇌전 = 뇌전제비보 (S+)
```
