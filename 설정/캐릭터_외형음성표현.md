## 🏫 무림아카데미학원

### 1. 장무명 (학원장)

**외형**:
```
신장: 178cm
체형: 여유로운 중년 체형, 은은한 근육
피부: 건강한 밀색
모발: 백발에 검은 머리 섞임, 중간 길이, 뒤로 넘김
안색: 온화하면서도 위엄 있는 얼굴
눈동자: 깊은 갈색, 세상 모든 것을 꿰뚫어보는 눈빛
수염: 턱수염 깔끔하게 정돈
옷차림: 백색 도포, 학원장 문장이 새겨진 허리띠

특징:
- 항상 잔잔한 미소
- 손에 찻잔을 들고 있는 경우 많음
- 걸을 때 발소리 없음
- 주변에 은은한 기운 발산
```

**음성**:
```
목소리 톤: 중저음의 차분한 남성 목소리
말투: 존댓말과 반말 적절히 혼용, 지혜로운 어조
특징:
- "호호호... 그렇지." (특유의 웃음)
- "괜찮다, 천천히 해도 된다."
- "자네가 선택한 길이라면 지켜보겠네."
- 말을 아끼지만 한마디 한마디가 무게감
```

**표정/제스처**:
```
기본 표정: 잔잔한 미소
버릇:
- 찻잔을 홀짝이며 생각하기
- 한 손을 등 뒤로 돌리고 걷기
- 중요한 말 전 잠시 침묵
- 제자들 머리 쓰다듬기

긴장 신호:
- 찻잔 내려놓기
- 눈빛이 날카로워짐
- 주변 온도 하강
- 일어서기 (평소 앉아있음)
```

### 2. 검술교사 혈무영 (여성)

**외형**:
```
신장: 172cm
체형: 날씬하지만 탄탄한 검사 체형
피부: 창백한 백색 (햇빛 잘 안 쐼)
모발: 새까만 장발, 높은 포니테일
안색: 냉미인형, 날카로운 이목구비
눈동자: 핏빛 붉은색 (혈마지체 특성)
    - 평상시: 검은색으로 위장
    - 감정 고조 시: 붉게 변함
옷차림: 검은 검도복 + 붉은 허리띠
    - 항상 검 휴대
    - 어머니 스카프 목에 (하얀색)

특징:
- 등에 X자 흉터 (과거 사고)
- 왼손에 검 굳은살
- 매서운 눈빛
- 피 냄새 싫어해서 향수 뿌림
```

**음성**:
```
목소리 톤: 낮고 차가운 여성 목소리
말투: 간결하고 직설적, 존댓말
특징:
- "...하거라." (명령형)
- "쓸데없는 질문이다."
- "검에 집중하라."
- "........." (침묵 多)

감정별:
- 평상시: 무표정 + 낮은 톤
- 화날 때: 더 차가워짐
- 드문 칭찬: "...나쁘지 않다."
```

**표정/제스처**:
```
기본 표정: 무표정, 차가운 얼굴
버릇:
- 검자루 만지작거리기
- 머리카락 뒤로 넘기기
- 팔짱 끼고 서있기
- 눈 감고 명상

긴장 신호:
- 눈동자 붉어짐
- 손이 검으로 이동
- 살기 발산
- 주변 온도 하강
```

### 3. 의술교사 독고선 (여성)

**외형**:
```
신장: 168cm
체형: 탄력있는 몸매, S라인
피부: 건강한 밀색, 광택 有
모발: 보라색 웨이브 장발, 한쪽으로 늘어뜨림
안색: 마성적인 미인, 요염한 이목구비
눈동자: 에메랄드 그린 (독 사용 시 보라색으로 변함)
귀: 약병 모양 귀걸이
손: 길고 가느다란 손가락, 보라색 매니큐어
옷차림: 흰색 의사 가운 (속은 세련된 의상)
    - 가운 곳곳에 약병과 독병
    - 보라색 스카프

특징:
- 항상 약 냄새와 향수 냄새 혼합
- 웃을 때 입꼬리 올라감
- 가슴 부분에 사천당문 문장 자수
- 항상 실험 도구 휴대
```

**음성**:
```
목소리 톤: 청아하면서도 장난기 있는 여성 목소리
말투: 반말, 친근하지만 가끔 무서운 말
특징:
- "호호~ 이거 먹어볼래?"
- "이건 독이야~♡ 아니면 약일지도?"
- "ENTP답게 실험해볼까?"
- "죽지는 않아! ...아마도?"

감정별:
- 장난칠 때: 밝고 경쾌한 톤
- 진지할 때: 차분하고 지적인 톤
- 화날 때: 냉소적이고 위험한 톤
```

**표정/제스처**:
```
기본 표정: 장난스러운 미소
버릇:
- 손으로 입 가리며 웃기
- 약병 만지작거리기
- 머리카락 한 올씩 만지기
- 상대 턱 들어올리며 말하기

특징:
- 실험 성공 시 환하게 웃음
- 실패 시 아쉬워하며 혀 차기
- 관심 있는 대상에게 가까이 다가감
```

### 4. 불도깨비 화염 (남성)

**외형**:
```
신장: 190cm
체형: 근육질, 탄탄한 전사 체형
피부: 붉은 기운 도는 갈색
모발: 불꽃처럼 솟구친 붉은 머리
안색: 호전적이지만 시원시원한 얼굴
눈동자: 불꽃색 (주황+빨강)
뿔: 이마에 붉은 뿔 2개 (15cm)
옷차림: 도깨비 전통 복장 + 근육 드러나는 상의
    - 허리에 방망이
    - 붉은 바지 + 맨발

특징:
- 몸에서 열기 발산
- 흥분하면 머리카락이 불타오름
- 방망이는 변신 가능 (작아졌다 커짐)
- 엄청난 식탐 (고기 선호)
```

**음성**:
```
목소리 톤: 우렁찬 남성 목소리, 큰 소리
말투: 반말, 호탕하고 직설적
특징:
- "으랴차차! 불타오르라!"
- "크하하! 재밌는데!"
- "싸우자! 전투다!"
- "배고프다! 고기!"

특유의 웃음: "크하하하!"
```

**표정/제스처**:
```
기본 표정: 크게 웃는 호탕한 얼굴
버릇:
- 방망이 어깨에 메고 걷기
- 주먹 쥐고 하늘로 들기
- 크게 웃으며 상대 어깨 치기
- 전투 시 뿔에서 불꽃

흥분 신호:
- 머리카락 불타오름
- 몸에서 연기 피어오름
- 방망이 커짐
- 눈에서 불꽃
```

**음성**:

목소리 톤: 밝고 경쾌한 여성 목소리
