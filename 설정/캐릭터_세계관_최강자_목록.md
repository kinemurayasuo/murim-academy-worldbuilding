# 세계관 최강자 목록 (EX 등급 보유자)

---

## 🌟 EX 등급 기준

**정의**: 세계관 최강급, 천년에 한 명 나올까 말까 한 존재
**전투력**: 10,000,000 이상
**특징**: 혼자서 국가급 위협, 자연재해급 파괴력

---

## 👤 인간계 EX급

### 1. 고금제일검신 검황(劍皇)

**이름**: 본명 미상, 검황(劍皇)으로만 알려짐
**나이**: 추정 90세
**소속**: 무소속 (은둔 중)
**전투력**: 50,000,000 (인간 최강)

**능력**:
- 천검만류: EX급 (모든 검법의 근원)
- 검기외방: 100km 밖 목표 소멸
- 검심: 검으로 세상 이치 깨달음
- 일검천하: 하늘을 가르는 검

**일화**:
- 50년 전 마왕 봉인에 참여
- 한 검에 산맥을 반으로 가름
- 제자 없음 (아무도 따라올 수 없음)
- 현재 위치 미상

**별명**: "천하제일검", "검의 신"

## 🔮 현재 세력 균형

```
인간계:
- 정파 (천무제)
- 사파 (천마대제)
→ 세력 균형

비인간계:
- 요괴 (백월왕) - 중립
- 도깨비 (각시) - 우호
- 용족 (흑룡왕) - 수면
→ 평화 유지

천계 vs 마계:
- 천사장 vs 마왕 (봉인)
→ 긴장 상태

은둔자:
- 검황, 귀곡자, 천산신의
→ 불간섭
```

## 🎯 학생들의 위치

```
EX급 (10,000,000+)
     ↑
     ↑ 넘사벽
     ↑
SSS급 (1,000,000+)
     ↑ 전설과 고수의 벽
     ↑
SS급 (500,000+)
     ↑ 절정의 벽
     ↑
S급 (100,000+)
     ↑ 일류의 벽
     ↑
A급 (50,000+) ← 학원 1등 (강아란 52,000)
B급 (20,000+) ← 학원 평균
C급 (10,000+) ← 입학 기준
```

**현실**:
- 학생들은 아직 A급 수준
- EX급은 차원이 다른 존재
- 성장하면 SS~SSS급 도달 가능 (천재 한정)
- EX급 도달은... 천년에 한 명
