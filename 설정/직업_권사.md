# 권사 (拳士) 직업

## 📋 개요

**직업명**: 권사 (拳士)
**주 무기**: 맨주먹
**특징**: 강력한 타격, 단순하지만 강함
**대표 인물**: 용상나한, 철권왕, 천하제일권

---

## ⭐ 직급 체계

### 전설
- **권제** (拳帝) - 주먹의 황제
- **권성** (拳聖) - 주먹의 성인
- **권왕** (拳王) - 주먹의 왕

### 고급
- **권호** (拳豪) - 주먹의 호걸
- **권협** (拳俠) - 주먹의 협객
- **권사** (拳士) - 주먹의 무사

### 중급
- **견습 권사** - 수련 중
- **초보 권사** - 입문

---

## 💪 직업 특성

### 장점
1. **최강 파괴력**: 단일 타격력 최고
2. **단순함**: 복잡한 기교 불필요
3. **무기 불필요**: 맨손이 무기
4. **높은 체력**: 육체 단련 기본
5. **돌파력**: 방어 파괴 특화

### 단점
1. **사거리 짧음**: 근접전만 가능
2. **기교 부족**: 화려함 없음
3. **연속기 적음**: 단타 위주
4. **방어 약함**: 공격 특화

## 👊 전문 분야

- 일격필살
- 최강 타격력
- 방어 무시
- 단순 명료

**대표 권법**:
- 벽력신권
- 파산권
- 천붕권

**적합 성격**: 직선적, 용맹

**능력치 배분**:
- 힘: 100%
- 체력: 80%
- 기타: 50%

---

- 100연타 가능

**대표 권법**:

- 체력: 80%

---

**능력치 배분**:

## 🎪 코믹 요소

### 권사의 일상
```
아침:
"배고파" → 10인분 먹음
"운동하자" → 산 오름

점심:
"배고파" → 20인분 먹음
"쉬자" → 바위 들기

저녁:
"배고파" → 30인분 먹음
"자자" → 철판 깔고 잠
```

### 권사의 고민
1. **너무 강해서**: 조절 못 함
   - 악수 → 손 부러짐
   - 등 두드림 → 날아감
   - 쓰다듬기 → 머리 눌림

2. **배고픔**: 항상 배고픔
   - 3시간마다 식사
   - 식비 폭탄
   - "또 먹어?!"

3. **단순함**: 생각 없음
   - "때리면 되잖아?"
   - "그냥 부수면 되는데?"
   - "복잡한 건 싫어"
