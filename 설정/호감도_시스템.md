# 호감도 시스템 (Affection System)

---

## 📊 호감도 시스템 개요

### 호감도 단계
```
0 ~ 100 단계 시스템
- 0~24: 적대/무관심
- 25~49: 지인/동료
- 50~74: 친구/호감
- 75~89: 호감/애정
- 90~99: 사랑/연인 직전
- 100: 운명/영혼의 반려
```

### 호감도 변화 속도
```
일반 대화: +1 ~ +3
선물: +5 ~ +15
퀘스트 완료: +10 ~ +30
중요 선택지: +20 ~ +50 or -20 ~ -50
배신/적대 행위: -50 ~ -100
```
