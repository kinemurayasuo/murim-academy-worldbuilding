# 방외인 (方外人) - 세상 밖의 사람들

---

## 📖 방외인이란?

**정의**: 정사파, 마교, 조정, 어느 곳에도 속하지 않는 자유인
**의미**: 틀(方) 바깥(外)에 있는 사람(人)
**특징**: 독자 생존, 자유로운 삶, 중립 유지

**이념**: "어디에도 얽매이지 않는다"

## 🤝 각 세력과의 관계

### vs 정파
```
관계: 중립
거래: 가능 (비밀)
갈등: 가끔 (정의 충돌)
```

### vs 사파
```
관계: 중립
거래: 빈번
갈등: 배신 시
```

### vs 요괴
```
관계: 우호
이유: 차별받는 동질감
협력: 많음
```

### vs 사도계
```
관계: 복잡
수용: 피해자는 받아줌
거부: 악행자는 거절
```

### vs 조정
```
관계: 묵인
거래: 비밀리
갈등: 드묾
```
