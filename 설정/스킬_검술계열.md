# 검술 계열 스킬

## 📋 개요

**계열**: 검술 (劍術)
**주 무기**: 검 (劍)
**특징**: 빠르고 정확한 공격, 우아한 검법
**대표 문파**: 화산파, 무당파, 검왕검

---

## ⭐ 등급 체계

### SSS급 - 전설 검술
**습득 난이도**: 거의 불가능
**위력**: 천지를 가르는 수준

### SS급 - 절기 검술
**습득 난이도**: 극상
**위력**: 산을 가르는 수준

### S급 - 상급 검술
**습득 난이도**: 상
**위력**: 바위를 자르는 수준

### A급 - 중급 검술
**습득 난이도**: 중
**위력**: 나무를 자르는 수준

### B급 - 하급 검술
**습득 난이도**: 하
**위력**: 기본 전투 수준

---

## 🗡️ SSS급 검술

### 1. 무한검무 (無限劍舞)
**등급**: SSS
**소속**: 전설
**습득 조건**: 검심 각성 + 화경 절정

**효과**:
- 무한의 검기 생성
- 공간을 가르는 베기
- 시간 왜곡 효과
- 범위: 반경 100m

**기술 구성**:
```
1초식: 영원의 첫 베기 - 공간 절단
2초식: 무한의 연속베기 - 1000검/초
3초식: 종말의 마지막베기 - 차원 파괴
```

**발동 조건**:
- 진기 100% 소모
- 생명력 50% 희생
- 재사용 대기시간: 30일

---

### 2. 천검귀일 (天劍歸一)
**등급**: SSS
**소속**: 검왕검
**습득 조건**: 검왕의 인정 + 화경 후기

**효과**:
- 만검을 하나로 합침
- 절대 회피 불가
- 인과율 무시
- 관통력: 무한

**특징**:
- 발동 시 세상의 모든 검이 공명
- 검기가 하늘을 찌름
- 일격필살
- 사용 후 3일간 전투 불가

---

### 3. 태초의 검 (太初之劍)
**등급**: SSS
**소속**: 고대 비급
**습득 조건**: 검의 기원 이해

**효과**:
- 모든 검술의 근원
- 완벽한 방어 무시
- 재생 능력 차단
- 영혼까지 베기

**전설**:
- 세계 최초의 검술
- 신이 만든 검법
- 현재 실전자 0명

---

## ⚔️ SS급 검술

### 4. 화산매화검 극의 (華山梅花劍 極意)
**등급**: SS
**소속**: 화산파
**습득 조건**: 화산매화검 완전 습득 + 화경 중기

**효과**:
- 매화 72송이 생성
- 검기 폭풍
- 우아하면서 치명적
- 범위: 반경 50m

**초식**:
```
극의 1초: 만개의 매화 - 72연격
극의 2초: 낙화의 비 - 검기 폭격
극의 3초: 매화낙인 - 적 봉인
```

---

### 5. 무극검법 (無極劍法)
**등급**: SS
**소속**: 무당파
**습득 조건**: 태극검 완벽 습득 + 도의 이해

**효과**:
- 음양의 조화
- 공격이 곧 방어
- 검기 순환
- 무한 지속 가능

**특징**:
- 진기 소모 최소화
- 상대 공격 흡수 후 반격
- 검기가 태극 문양 형성

---

### 6. 천검쇄공 (天劍碎空)
**등급**: SS
**소속**: 독립 비급
**습득 조건**: 공간 이해 + 화경 초기

**효과**:
- 공간을 베어 이동
- 순간 이동 가능
- 검기 차원 저장
- 예측 불가 공격

**응용**:
- 공간 검: 차원 너머 공격
- 허공보: 공중 이동
- 차원참: 공간 파괴

## 🎯 스킬 조합 시스템

### 검술 + 검술
```
화산매화검 + 뇌전검 = 뇌전매화검 (S+)
태극검 + 빙설검 = 빙극검 (S+)
```

### 검술 + 신법
```
폭풍검무 + 신행보 = 폭풍보검무 (SS-)
```

### 검술 + 내공
```
천검쇄공 + 선천기공 = 선천검강 (SSS-)
```
