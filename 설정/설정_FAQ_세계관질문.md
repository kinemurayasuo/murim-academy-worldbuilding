# FAQ - 자주 묻는 질문

## 🌍 세계관 관련

### Q1: 일반인도 무공을 알고 있나요?
```
A: 네, 알고 있습니다.

- 2000년대 초반 "무림 대공개" 사건
- 정부가 무림 존재 공식 인정
- 현재는 일상에 통합됨
- 무림청이 관리

일반인 인식:
- 무공 = 특수 능력
- 무림인 = 운동선수 같은 존재
- TV, SNS로 친숙함
- 동경의 대상
```

### Q2: 일반인도 무공을 배울 수 있나요?
```
A: 가능하지만 어렵습니다.

재능 필요:
- 내공 감각 (10명 중 1명)
- 꾸준한 수련
- 시간과 돈

현실:
- 대부분 중도 포기
- 취미 수준 가능
- 고수는 재능 필요

학원 입학:
- 최소 전투력 5,000+
- 일반인은 힘듦
```

### Q3: 무림인은 얼마나 되나요?
```
A: 전체 인구의 약 1%

한국 기준:
- 전체 인구: 5000만
- 무림인: 약 50만명
- 고수 (A급+): 4만명
- 절정고수 (S급+): 1000명
- 화경 고수: 100명
- 초월자: 10명

학생:
- 무림 학원: 전국 20개
- 총 학생: 5만명
```

### Q4: 무림인은 어떻게 먹고 사나요?
```
A: 다양한 직업이 있습니다.

정식 직업:
- 무림청 공무원
- 학원 교관
- 보디가드
- 무림 연예인
- 검튜버

프리랜서:
- 용병
- 호위
- 헌터 (마수 사냥)
- 탐험가

문파 소속:
- 문파 지원
- 임무 수행
- 월급제
```
