# 음악가 (音樂家) 직업

## 📋 개요

**직업명**: 음악가 (音樂家)
**주 무기**: 악기, 음파
**특징**: 광역 공격/보조, 정신 공격, 예술성
**대표 인물**: 음공대사, 칠현금마, 천악선녀

---

## ⭐ 직급 체계

### 전설
- **음제** (音帝) - 음악의 황제
- **음성** (音聖) - 음악의 성인
- **음왕** (音王) - 음악의 왕

### 고급
- **음호** (音豪) - 음악의 호걸
- **음협** (音俠) - 음악의 협객
- **음사** (音士) - 음악의 무사

### 중급
- **견습 음악가** - 수련 중
- **초보 음악가** - 입문

---

## 💪 직업 특성

### 장점
1. **광역 효과**: 범위 공격/보조
2. **정신 공격**: 방어 어려움
3. **보조 능력**: 아군 강화
4. **예술성**: 아름다움
5. **다재다능**: 공격/치유/보조

### 단점
1. **악기 의존**: 악기 없으면 약함
2. **귀막힘**: 귀 막으면 약화
3. **준비 시간**: 연주 필요
4. **근접 약함**: 직접 전투 불리
5. **소음 민감**: 시끄러우면 집중 어려움

## 🎵 전문 분야

### 1. 거문고 연주자
**특화**: 공격 음공

**특징**:
- 보이지 않는 검기
- 7현 각각 효과
- 우아한 공격
- 중거리 특화

**대표 곡**:
- 칠현무형검
- 천지대곡
- 섬광곡

**악기**: 7현금

**전투 스타일**:
- 연주 중 검기 발사
- 음표마다 공격
- 연속 타격

**적합 성격**: 우아함, 지적

## 🎪 코믹 요소

### 음악가의 고민
```
1. 음치 음악가
"도~레~..."
→ 음정 엉망
→ 적: "귀 아파!!"
→ 의도치 않은 공격

2. 악기 고장
"중요한 공연인데..."
→ 현 끊어짐
→ "..."

3. 시끄러운 환경
"집중이..."
→ 옆에서 공사
→ "연주 못 해!!"
```

### 실수 사례
1. **틀린 곡 연주**
   - 공격곡 → 치유곡
   - 적: "...고맙다?"

2. **악보 잘못 봄**
   - 엉뚱한 곡
   - "이거 아닌데..."

3. **떨림**
   - 실전에서 긴장
   - 손 떨림
   - 음 틀림
