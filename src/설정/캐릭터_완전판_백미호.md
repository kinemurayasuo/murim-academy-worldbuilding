```
  - 오빠와의 경쟁 구도 형성
  - 하지만 본인은 자유로운 생활을 원함

■ 1미 → 2미 (100세)
  - 첫 꼬리 각성: 50세 (매우 이른 나이)
  - 둘째 꼬리 각성: 100세
  - 재능을 인정받아 요괴계에서 "은빛 신동" 칭호

■ 2미 → 3미 (200세)
  - 셋째 꼬리 각성: 200세
  - 이 시기 인간 마을에 몰래 내려감
  - 처음으로 "인간 남자"에게 호기심 느낌
  - 하지만 정체 들통나 위기 → 부모가 구출
```

### 교환학생 계기 (260세~현재)
```
■ 인간 세계에 대한 동경
  - 인간들의 "SNS", "스마트폰" 문화에 빠짐
  - 요괴계는 너무 고루하고 답답하다고 느낌
  - "인간 세상에서 살고 싶어!" 가출 시도 3회

■ 부모와의 타협
  - 아버지: "그럼 무림아카데미에 교환학생으로 가라"
  - 조건 1: 여우 구슬 봉인 (매혹술 남용 방지)
  - 조건 2: 4미 각성 전까지 돌아올 것
  - 조건 3: 인간 남자와 사랑 금지

■ 무림아카데미 입학 (현재 27년차)
  - 외형 나이 18세로 위장
  - 요괴계 교환학생 자격으로 입학
  - 목표: "인간 세계 경험" + "SNS 스타 되기"
  - 숨겨진 목표: "진짜 사랑 찾기" (본인도 무의식)
```

### 현재 상황
```
■ 아카데미 최고 인기 여학생
  - SNS 팔로워 50만 명
  - 매일 셀카 인증, 일상 브이로그 업로드
  - "미호언니" 팬클럽 3,000명
  - 온갖 고백 러시 (하지만 다 거절)

■ 4미 각성의 기로
  - 최근 들어 꼬리 끝이 자주 떨림 (각성 조짐)
  - 아버지로부터 귀환 명령 계속 들어옴
  - "아직 인간 세계 더 보고 싶어!" 버티는 중
  - 하지만 시간이 얼마 남지 않음

■ 플레이어와의 만남
  - 첫 만남: "헤헤~ 너 새로 전학 온 애구나? 나랑 친구 할래?"
  - 처음엔 가벼운 장난으로 접근
  - 하지만 점점 진심으로 빠져듦
  - 고민: "이 감정이... 사랑인가?"

■ 숨겨진 위기
  - 요괴계에서 미호를 데려가려는 추격자 파견
  - 오빠 백은진: "누나, 이제 돌아가야 해. 가문의 의무야."
  - 미호: "싫어! 난 여기서 더 있을 거야!"
  - 만약 4미 각성하면 강제 소환 가능성
```

## 9. 인간관계 (Relationships)

### 가족
```
【아버지: 백은천 (칠미호왕)】
관계: 엄격하지만 딸을 사랑하는 아버지
- 미호를 차기 당주로 키우려 함
- "넌 우리 가문의 미래다"
- 하지만 딸의 자유를 억압한다는 것을 모름
- 미호의 감정: 존경하지만 답답함

【어머니: 설화란 (육미선녀)】
관계: 자상하고 이해심 많은 어머니
- "미호야, 네 마음대로 살아도 괜찮아"
- 몰래 딸의 인간 세계 생활 응원
- 가끔 스마트폰으로 영상통화
- 미호의 감정: 가장 의지하는 사람

【오빠: 백은진 (오미호군)】
관계: 경쟁자이자 보호자
- 동생의 재능을 질투하면서도 사랑함
- "내가 당주가 되어서 너를 자유롭게 해주겠어"
- 요괴계에서 미호 데려오라는 임무 받음
- 미호의 감정: 오빠는 좋지만 간섭은 싫어
```

### 학원 내 관계
```
【강아란】
관계: 절친이자 라이벌
- 서로 학원 최고 미녀 자리 두고 경쟁
- "아란아~ 오늘 내 셀카 '좋아요' 1000개 넘었어!"
- "흥! 내 건 1500개야!"
- 하지만 진짜 친구, 서로의 고민 상담 상대

【혈소연】
관계: 무서운 선배
- 미호의 가벼운 장난을 찬물 끼얹듯 제압
- "시끄러워. 조용히 해."
- 미호: "으으... 소연 선배만 보면 꼬리가 쫑긋..."
- 천적 같은 존재

【운소아】
관계: 귀여운 후배
- "미호 선배! 저도 SNS 스타 되고 싶어요!"
- 미호: "헤헤~ 내가 가르쳐줄게♡"
- 함께 셀카 찍고 놀러 다니는 사이

【설무연】
관계: 신비로운 친구
- 무연의 빙설 기운이 미호의 불 약점 보완
- "무연아, 너 옆에 있으면 시원해서 좋아~"
- 서로 과묵함 vs 수다쟁이로 대조적

【선생들】
- 백설화 (여우 선배): "설화 선배님! 9미는 어떤 느낌이에요?"
- 혈무영 (검술 선생): "미호, 네 검술 재능은... 글쎄다."
- 독고선 (의술 선생): "선생님! 꼬리 아플 때 약 있어요?"
```

### 특수 관계
```
【플레이어 (주인공)】
관계: ??? (호감도에 따라 변화)

■ 호감도 1단계 (0~25):
  - "헤헤~ 너 재미있는 애네? 놀아줄까?"
  - 가벼운 장난, 매혹술로 놀리기
  - 친구 이상 호감 미만

■ 호감도 2단계 (26~50):
  - "어? 이 애랑 있으면 편한데?"
  - 진짜 친구로 인정
  - 고민 상담, 속마음 조금씩 보임

■ 호감도 3단계 (51~75):
  - "이 감정이 뭐지? 두근두근..."
  - 연애 감정 자각
  - 플레이어 주변 여자들에게 질투
  - "나만 봐!"

■ 호감도 4단계 (76~99):
  - "좋아해... 진심으로."
  - 고백 이벤트 발생
  - 하지만 요괴와 인간의 사랑 고민
  - "우린... 함께할 수 있을까?"

■ 호감도 MAX (100):
  - "당신만 있으면 돼."
  - 4미 각성 + 사랑의 힘으로 봉인 해제
  - 엔딩: 요괴계 거부하고 인간 세계 선택
  - OR 함께 요괴계로 가서 새로운 길
```

## 10. 좋아하는 것 / 싫어하는 것

### 좋아하는 것
```
■ SNS 활동
  - 셀카 찍기, 브이로그 편집, 댓글 확인
  - "오늘 '좋아요' 몇 개일까~?"
  - 새로운 필터 시도하는 거 좋아함

■ 패션/뷰티
  - 최신 유행 옷, 화장품 수집
  - "이번 시즌 트렌드는 분홍색이야!"
  - 명품 가방, 액세서리 컬렉션

■ 단 음식
  - 과일, 케이크, 아이스크림 특히 좋아함
  - "딸기 케이크 최고야~♡"
  - 여우족 특성상 단맛에 약함

■ 칭찬/관심
  - "미호 예쁘다" 말 들으면 꼬리 흔들림
  - 인기/관심받는 거 자체가 에너지원
  - 무시당하는 게 제일 싫음

■ 자유로운 생활
  - 규칙/의무 없이 하고 싶은 대로
  - 밤새 놀기, 여행 가기
  - "인생은 즐기는 거야!"

■ 달빛
  - 여우족은 달빛 아래서 요기 충전
  - 보름달 밤에 변신 능력 최강
  - "달이 예쁜 날엔 기분이 좋아"
```

### 싫어하는 것
```
■ 불/열기
  - 체질적으로 불 속성 약점
  - 여름 더위 극혐
  - 화염 마법 보기만 해도 경계

■ 쇠/철
  - 철제 무기에 닿으면 요기 봉인
  - 철창, 쇠사슬 보면 본능적 공포
  - "저 무서운 거 치워줘!"

■ 신성한 물건
  - 불경, 십자가, 부적 등
  - 접촉 시 피부 화상
  - 교회/절 근처 가면 불편함

■ 무시/외면
  - 관심 안 받는 게 제일 싫음
  - "나를 못 본 척?! 화난다!"
  - SNS 좋아요 적으면 하루종일 우울

■ 구속/강요
  - 규칙, 의무, 책임감 답답해함
  - "왜 내 맘대로 못해?!"
  - 가문의 의무 강요가 제일 스트레스

■ 경쟁자 출현
  - 다른 예쁜 여자 나타나면 경계
  - "내가 제일 예쁜 거야!"
  - 플레이어 주변 여자들 견제

■ 거짓말 들키기
  - 사실 거짓말 자주 함 (여우니까)
  - 하지만 들키면 엄청 당황
  - "아... 그게... 그건..."
```

## 11. 15가지 감정별 말투 (15 Emotion-Based Speech Patterns)

### 1. 기쁨 (Joy)
```
"헤헤~ 기분 좋아♡ 오늘 하루 완전 럭키비키잖아!"
"와아~! 대박! 이거 완전 내 스타일인데?!"
"호호호~ 역시 나는 운이 좋아~ ♪"
```

### 2. 슬픔 (Sadness)
```
"흑... 슬퍼... (꼬리 축 늘어짐)"
"왜 이러는 거야... 나 뭐 잘못한 거야...?"
"...혼자 있고 싶어. 잠깐만..."
```

### 3. 분노 (Anger)
```
"화났어! 진짜 화났다고!"
"흥! 이 나쁜 남자! 다시는 안 봐!"
"으르렁... (송곳니 드러남) 더 이상 참지 않을 거야!"
```

### 4. 두려움 (Fear)
```
"무, 무서워... (꼬리를 꼭 감싸 안음)"
"저거... 저거 무섭잖아! 치워줘!"
"으으... 도망가고 싶어..."
```

### 5. 놀람 (Surprise)
```
"헉?! 뭐야 이게?!"
"깜짝이야! 심장 떨어질 뻔했잖아!"
"에엑?! 진짜?! 대박!"
```

### 6. 혐오 (Disgust)
```
"으웩... 이게 뭐야, 더러워..."
"싫어! 저리 치워!"
"꼴도 보기 싫어, 흥!"
```

### 7. 기대 (Anticipation)
```
"궁금해~ 빨리 보여줘!"
"기대된다♡ 뭐가 나올까~?"
"설렌다 설레~ 어떻게 될까?"
```

### 8. 신뢰 (Trust)
```
"너라면 믿을 수 있어."
"괜찮아, 난 네 편이야."
"...고마워. 진심으로."
```

### 9. 당황 (Embarrassment)
```
"으아아! 이, 이건 오해야!"
"아... 그게... 그건... (귀 발갛게)"
"잠깐! 지금 이상한 거 아니거든?!"
```

### 10. 질투 (Jealousy)
```
"누구야 저 여자?! 왜 웃고 있어?!"
"흥! 나만 봐! 다른 데 보지 마!"
"...나보다 예쁘진 않은데? (속으로 경계)"
```

### 11. 외로움 (Loneliness)
```
"...혼자는 싫어. 곁에 있어줘."
"다들 어디 간 거야... 나만 혼자..."
"이렇게 조용하니까... 무섭기도 하고..."
```

### 12. 자랑/뽐냄 (Pride)
```
"헤헤~ 나 대단하지? 인정해!"
"이 정도는 나한테 식은 죽 먹기야~"
"역시 나야, 나! 칭찬해줘도 돼~♡"
```

### 13. 사랑 (Love)
```
"좋아해... 정말로."
"너랑 있으면... 행복해."
"...바보. 눈치도 없어. (얼굴 붉힘)"
```

### 14. 장난 (Playfulness)
```
"헤헤~ 걸렸지? 내가 한 거야~"
"이걸로 네가 당황하는 거 보고 싶었어♡"
"재밌지? 더 놀아줄까?"
```

### 15. 진지함 (Seriousness)
```
"지금은 진심으로 말하는 거야."
"장난 아니야. 정말이라고."
"...잘 들어줘. 이건 중요한 얘기야."
```

## 12. 행동 패턴 (Behavior Patterns)

### 일상 패턴
```
■ 아침 (06:00~09:00)
  - 기상 후 1시간 동안 SNS 확인
  - 셀카 10장 찍어서 베스트 1장 업로드
  - "오늘의 미호♡" 해시태그
  - 아침 먹으면서 댓글 확인
  - "어머~ 이 댓글 귀여워~"

■ 오전 수업 (09:00~12:00)
  - 수업 집중도: 30%
  - 나머지는 스마트폰 만지작
  - 가끔 선생님께 혼남
  - "미호, 폰 그만 보고 집중!"
  - 쉬는 시간마다 화장 고침

■ 점심 (12:00~13:00)
  - 친구들과 카페테리아
  - 음식 사진 먼저 찍기 (필수)
  - "#오늘점심 #맛스타그램"
  - 대화 주제: 주로 연애, 패션, SNS

■ 오후 수업 (13:00~16:00)
  - 졸음과의 전쟁
  - 창밖 보며 멍 때리기
  - "하아... 빨리 끝나면 좋겠다..."
  - 가끔 꼬리(환상) 끝을 입으로 물며 생각

■ 방과 후 (16:00~19:00)
  - SNS 컨텐츠 제작 시간
  - 셀카, 브이로그, 댄스 영상 촬영
  - 편집 후 업로드
  - 실시간 '좋아요' 확인

■ 저녁 (19:00~22:00)
  - 친구들과 시내 나가기
  - 쇼핑, 카페, 노래방
  - 가는 곳마다 인증샷
  - "#미호의하루 #일상스타그램"

■ 밤 (22:00~24:00)
  - 기숙사 돌아와서 셀프 케어
  - 피부 관리, 헤어 관리
  - 달 보며 요기 충전 (필수)
  - 부모님께 영상통화

■ 심야 (00:00~02:00)
  - 본격 SNS 활동 시간
  - 라이브 방송, 팬들과 소통
  - "오늘 뭐 했는지 궁금하지~?"
  - 댓글 하나하나 읽고 답장
```

### 전투 패턴
```
■ 전투 스타일: 기만형 환술사
  - 정면 돌파 ✗ / 교란과 속임수 ✓
  - 분신으로 적 혼란 유도
  - 진짜는 뒤에서 환술 전개

■ 전투 시작
  1. 은광천무로 고속 이동
  2. 3개 분신 생성 (구미환생술)
  3. 환술로 시야 차단 (여우비 내리는 밤)
  4. 적이 헤매는 동안 후방 기습

■ 전투 중
  - 꼬리 공격 (여우몽환각) 주력
  - 매혹술로 적 무력화 시도
  - 장거리 전투 선호, 근접전 약함
  - 위험하면 즉시 도주 (생존 우선)

■ 긴급 상황
  - 3미 완전 해방 (최후의 수단)
  - 요기 폭발로 모든 능력 2배
  - 단, 1시간 후 기력 소진
  - 도망칠 수 없을 때만 사용

■ 협동 전투
  - 아군에게 환술 버프 제공
  - 적에게 매혹/혼란 디버프
  - 후방 지원형 역할
  - "내가 길 만들어줄게! 지금 가!"
```

### 연애 패턴
```
■ 호감 표현 방식
  - 스킨십 많아짐 (팔짱, 어깨에 기대기)
  - 매일 아침 문자 "잘 잤어?"
  - 셀카 보내기 "오늘 나 어때?"
  - 같이 다니려고 함 (어디든)

■ 질투할 때
  - 다른 여자 옆에 바짝 붙어서 영역 표시
  - "저 여자 누구야?" 직설적 질문
  - 삐져서 말 안 걸기
  - 하지만 금방 풀림 (관심 주면)

■ 데이트 선호
  - 인스타 감성 카페 가기
  - 쇼핑몰 데이트 (쇼핑백 들어주기)
  - 놀이공원 (SNS 인증샷 필수)
  - 야경 맛집 (달 보이는 곳 선호)

■ 고백받았을 때
  - 처음엔 당황 "에...? 진짜?"
  - 요괴와 인간 사랑 고민
  - "나... 너한테 숨긴 게 있어..."
```

## 13. 트리거 & 약점 (Triggers & Weaknesses)

### 감정 트리거
```
■ 기쁨 트리거
  - '좋아요' 1000개 넘으면 기분 최고
  - "예쁘다" 칭찬 들으면 꼬리 흔들림
  - 맛있는 디저트 먹을 때
  - 좋아하는 사람이 관심 줄 때

■ 분노 트리거
  - 무시당하거나 외면당할 때
  - 다른 여자가 호감 대상 접근할 때
  - SNS 악플 (특히 외모 비하)
  - 가문의 의무 강요당할 때

■ 슬픔 트리거
  - "넌 요괴니까 이해 못 해" 같은 말
  - 정체성 혼란 ("난 뭐지? 요괴? 인간?")
  - 부모님의 귀환 명령 연락
  - 좋아하는 사람이 자신을 거부할까 봐 두려울 때

■ 두려움 트리거
  - 불 속성 공격/화염 마법
  - 철제 무기 (요기 봉인 위험)
  - 신성한 물건 (부적, 십자가 등)
  - "4미 각성하면 인간 세계 못 와" 경고
```

### 전투 약점
```
■ 속성 약점
  - 불 속성 공격: 피해 150%
  - 철제 무기: 요기 봉인 (3턴간 능력 -50%)
  - 신성 마법: 직접 피해 + 지속 화상

■ 전술 약점
  - 환술 간파 능력 (천안통, 정신력 SS)
  - 광역 물리 공격 (분신 무력화)
  - 지속전 (기력 소모 빠름)
  - 근접 난전 (체술 약함)

■ 심리 약점
  - 매혹술 무효화 (순수한 마음)
  - "요괴는 인간을 속이는 존재" 편견
  - 가족/친구를 인질로 잡히면 무력화
  - 정체 들통나는 것에 대한 공포

■ 생리적 약점
  - 더운 날씨에 기력 소모 빠름
  - 철 냄새만 맡아도 몸이 굳음
  - 신성한 물에 닿으면 화상
  - 꼬리 잡히면 힘 못 씀 (여우족 공통)
```

### 숨겨진 약점
```
■ 진짜 사랑에 약함
  - 진심으로 사랑하면 요력 약화
  - 매혹술이 역효과 (상대에게 끌림)
  - 은미지체 특성: 사랑하면 인간화 시작
  - 4미 각성 조건과 충돌

■ 정체성 혼란
  - "나는 요괴인가 인간인가"
  - 양쪽 어디에도 완전히 속하지 못함
  - 인간 친구들: "넌 요괴잖아"
  - 요괴 가족들: "넌 인간을 닮아가고 있어"

■ 외로움
  - 겉으론 밝지만 속은 외로움
  - 진짜 자신을 보여줄 수 없음
  - "내 정체 알면 다들 날 무서워할까?"
  - SNS 인기는 진짜 친구가 아님을 앎

■ 가문의 압박
  - 차기 당주로서의 책임감
  - 아버지의 기대 vs 자신의 자유
  - "4미 각성 전에 돌아와야 해"
  - 시간이 얼마 남지 않음
```

## 14. 성장 아크 (호감도별) (Growth Arc by Affection Level)

### Phase 0: 첫 만남 (호감도 0)
```
상황: 플레이어 전학 첫날
이벤트: "헤헤~ 너 새로 온 애구나? 나랑 친구 할래?"
- 가벼운 호기심으로 접근
- 장난스럽게 매혹술 사용해보기
- "앗, 안 통하네? 재밌는데?"
- 관계: 관심 있는 신입생

성장: 없음 (아직 변화 전)
```

### Phase 1: 장난 상대 (호감도 1~25)
```
이벤트:
- "오늘 셀카 찍어줄래? 네가 찍으면 예쁘게 나올 것 같아~"
- 매일 아침 복도에서 마주치기
- "어? 너 어제 뭐 했어? 나 궁금해~"

관계 변화:
- 단순 친구 이상의 관심
- 자주 찾아오고 말 걸기
- 하지만 아직 가벼운 장난 수준

성장:
- 인간에 대한 이해 조금씩 증가
- "이 애는 나한테 솔직하네?"
```

### Phase 2: 진짜 친구 (호감도 26~50)
```
이벤트:
- 밤에 혼자 달 보며 울고 있는 미호 발견
- "...어? 왜 여기 있어? (눈물 닦으며) 아무것도 아니야!"
- 처음으로 약한 모습 보임
- 정체성 고민 고백: "난... 요괴도 인간도 아니야..."

관계 변화:
- 플레이어를 진짜 친구로 인정
- 가면 벗고 진심 대화 가능
- 고민 상담, 속마음 공유

성장:
- 외로움 조금씩 치유
- "이 사람은... 날 있는 그대로 봐주는 것 같아"
- 환술 의존 감소

퀘스트: 【은빛 여우의 눈물】
- 미호의 과거 이야기 듣기
- 가족과의 갈등 이해하기
- 보상: 미호의 은빛 꼬리 장식 (액세서리)
```

### Phase 3: 설렘의 시작 (호감도 51~75)
```
이벤트:
- 미호가 다른 남학생과 얘기하는 플레이어 보고 질투
- "누구야 저 여자?! ...아, 아니, 그냥 궁금해서!"
- 스스로 감정 자각 못함
- 친구들: "미호, 너 걔 좋아하는 거 아냐?"
- 미호: "에? 아, 아니야! (얼굴 빨개짐)"

관계 변화:
- 연애 감정 시작 (본인 자각 못함)
- 플레이어와 단둘이 있고 싶어함
- 스킨십 증가 (팔짱, 어깨 기대기)
- 다른 여자 접근 시 노골적 견제

성장:
- 사랑이라는 감정 처음 느낌
- 환술보다 진심으로 다가가려 노력
- "있는 그대로의 나를 보여줘도 될까?"

퀘스트: 【첫사랑의 멜로디】
- 미호와 놀이공원 데이트
- 페리스 휠에서 고백 타이밍 (선택지)
- 보상: 미호의 호감도 대폭 상승

위기 이벤트:
- 오빠 백은진 등장: "누나, 이제 돌아가야 해"
- 미호: "싫어! 난 여기 있을 거야!"
- 플레이어 선택: 미호 편들기 vs 중립 vs 오빠 편들기
```

### Phase 4: 사랑의 고백 (호감도 76~99)
```
이벤트:
- 만월의 밤, 미호가 플레이어를 옥상으로 부름
- "...할 말이 있어. 잘 들어줘."
- 정체 완전 공개: 여우 귀, 3개 꼬리 전부 드러냄
- "나... 사실 구미호야. 놀랐지?"
- "그래도... 좋아해. 진심으로."

선택지:
1. "나도 좋아해" → TRUE END 루트
2. "친구로만..." → SAD END 루트
3. "시간이 필요해" → NORMAL END 루트

TRUE END 선택 시:
- 미호: "정말? 진심이야? (눈물)"
- 포옹 CG
- "고마워... 날 받아줘서..."

관계 변화:
- 정식 연인 관계
- 더 이상 숨기지 않음
- 주변 사람들에게 공개 (용기)

성장:
- 정체성 확립: "난 요괴지만, 사랑할 수 있어"
- 자신감 증가
- 매혹술 아닌 진심으로 사랑받는 기쁨

위기 이벤트:
- 아버지 백은천 직접 등장
- "미호, 넌 가문의 미래다. 돌아가자."
- 플레이어와 미호, 함께 아버지 설득
```

### Phase 5: 운명의 선택 (호감도 100)
```
최종 이벤트: 【은미의 각성】

상황:
- 미호를 노리는 적 출현 (요괴계 암살자)
- 플레이어 위험에 처함
- 미호: "안 돼... 이 사람을...!"
- 4미 각성 조건 충족: 진짜 사랑의 깨달음

각성 연출:
- 은빛 광채 폭발
- 4번째 꼬리 출현
- 전투력 급상승: 250,000
- "내가... 지켜줄게."

전투 후:
- 미호: "이제... 가문으로 돌아가야 해."
- "4미 각성하면 요괴계가 날 소환할 수 있거든..."

최종 선택지: 【TRUE END 분기】

A. "함께 요괴계로 가자"
→ 요괴계 엔딩
- 플레이어도 요괴화 OR 특별 허가
- 함께 구미호 가문에서 살기
- 미호는 차기 당주, 플레이어는 배우자
- CG: 요괴계 궁전에서 손잡고 석양 바라보기

B. "인간 세계에 남자"
→ 인간 세계 엔딩
- 미호, 가문 의무 거부
- 5미 이상 각성 포기 (사랑 선택)
- 아카데미에서 계속 함께
- CG: 졸업식 후 함께 웃는 모습

C. "각자의 길을 가자"
→ 이별 엔딩 (BAD END)
- 미호 요괴계 귀환
- 플레이어 인간 세계 잔류
- 10년 후 재회 이벤트 (엔딩 크레딧 후)
- CG: 달빛 아래 등 돌리고 서 있는 두 사람

TRUE END (A or B 선택 시) 보상:
- 칭호: "은미의 연인"
- 아이템: "여우 구슬 목걸이" (미호의 요기 일부)
- 특전 CG: 웨딩 드레스 입은 미호
```

## 15. 숨겨진 설정 (Hidden Settings)

### 비밀 1: 여우 구슬의 진실
```
■ 미호의 목에 있는 은빛 구슬
  - 사실 미호의 생명력 그 자체
  - 구슬 파괴되면 미호도 사망
  - 부모가 봉인한 이유: 힘의 남용 방지

■ 구슬의 진짜 능력
  - 기억 조작 (과거 기억 삭제/변경)
  - 생명력 흡수 (키스로 상대 기력 흡수)
  - 환생 (1회 한정, 사망 시 부활)

■ 봉인 해제 조건
  - 4미 각성 + 진짜 사랑 깨달음
  - OR 부모의 직접 해제
  - OR 생명 위기 상황에서 자동 해제

■ 위험성
  - 구슬 완전 개방 시 이성 상실 가능성
  - 요괴 본성 폭주, 주변 사람 공격 가능
  - 미호 최대 공포: "내가 사랑하는 사람을 해칠까봐..."
```

### 비밀 2: 300년 전의 사랑
```
■ 미호의 숨겨진 과거
  - 사실 200년 전(미호 87세 때) 인간 남자 사랑한 적 있음
  - 이름: 이진우 (무림맹 소속 검사)
  - 서로 사랑했지만 신분 차이로 이별

■ 이별의 진실
  - 진우의 가문이 반대 (요괴와 인간)
  - 미호가 스스로 기억 삭제 (여우 구슬 능력 사용)
  - 하지만 무의식에 흔적 남아있음
  - 가끔 꿈에서 그를 봄

■ 현재와의 연결
  - 플레이어가 진우와 닮은 구석 있음
  - 미호가 끌린 이유 (무의식적 기억)
  - 숨겨진 퀘스트: 【잊혀진 기억】
    - 미호의 과거 기억 파편 수집
    - 진실 알게 되면 미호 대성통곡
    - "나... 다시 사랑해도 될까?"
```

### 비밀 3: 차기 당주 경쟁
```
■ 오빠 백은진과의 관계
  - 겉으론 사이 좋지만 속으론 경쟁
  - 은진: "미호가 당주 되면 가문 망한다"
  - 미호: "오빠는 고지식해서 싫어"

■ 은진의 계획
  - 미호를 인간 세계에서 데려오는 게 임무
  - 하지만 진짜 목적: 미호 실각시키기
  - "인간과 사랑 빠진 요괴는 당주 자격 없어"
  - 미호의 연애 증거 수집 중

■ 미호의 선택
  - 당주 자리 vs 사랑
  - "나... 사실 당주 하기 싫었어..."
  - 하지만 가문 의무 vs 개인 자유 갈등
```

```
  - 하지만 그렇게 되면 플레이어 기억 잃음

■ 선택의 기로
  - 9미 완성 (신 되기) vs 사랑 (인간으로 남기)
  - 가문의 기대 vs 개인의 행복
  - 영생 vs 유한한 사랑

■ 숨겨진 제3의 길

  - 조건: "진짜 사랑과 함께 승천"

  - CG: 함께 하늘로 올라가는 두 사람
```

## 17. 전투 스타일 (Combat Style)

### 기본 전투 스타일
```
■ 전투 철학
  - "정면 승부는 바보들이나 하는 거야~"
  - 속임수와 교란이 핵심
  - 적이 혼란스러울 때 마무리

■ 전투 3원칙
  1. 보이는 것을 믿지 마라 (환술)
  2. 먼저 도망칠 길을 확보하라 (생존)
  3. 1:1은 피하고 다수를 혼란시켜라 (전략)

■ 선호 전투 거리
  - 원거리 (10m+): ★★★★★ 최선호
  - 중거리 (5~10m): ★★★☆☆ 괜찮음
  - 근거리 (0~5m): ★☆☆☆☆ 회피

■ 전투 순서
  1. 환술로 시야 차단
  2. 분신 생성으로 숫자 우위
  3. 꼬리 공격으로 견제
  4. 매혹술로 무력화
  5. 도망 OR 마무리
```

### 스킬 세트
```
■ Q 스킬: 【삼미화생환】
  - 3중 환술 전개 (시각+청각+촉각)
  - 쿨타임: 30초
  - 효과: 적 명중률 -50%, 3초간 혼란

■ W 스킬: 【구미환생술】
  - 꼬리 1개로 분신 생성
  - 쿨타임: 60초
  - 효과: 본체 전투력 30% 분신 1개 소환
  - 최대 3개 동시 유지

■ E 스킬: 【미호의 유혹】
  - 눈 마주친 대상 매혹
  - 쿨타임: 45초
  - 효과: 단일 대상 3초간 행동 불가

■ R 스킬 (필살기): 【여우비 내리는 밤】
  - 광역 환술 전개
  - 쿨타임: 5분
  - 효과: 반경 100m 은빛 안개, 적 전원 이동속도 -70%
  - 지속: 10초

■ Passive: 【은미지체】
  - 달빛 아래 요기 자동 회복 (초당 5%)
  - 환술 능력 200% 증폭
  - 불 속성 피해 150% 받음
```

### 콤보 루트
```
■ 기본 콤보: (단일 대상)
  E(매혹) → 평타 → Q(환술) → 꼬리 공격 → 평타
  - 총 피해량: 약 30,000
  - 안정적이고 기본적인 콤보

■ 교란 콤보: (다수 대상)
  Q(환술) → W(분신 3개) → R(여우비) → 분신 공격 → 본체 도주
  - 적 혼란 극대화
  - 본체는 안전 확보

■ 생존 콤보: (위급 상황)
  W(분신) → Q(환술) → 은광천무(도주) → 적 추격 불가
  - 생존률 90%+
  - "싸워서 안 되면 도망가는 게 상책이야~"

■ 버스트 콤보: (3미 해방)
  3미 해방 → R(여우비) → W(분신 3개) → E(매혹) → 총공격
  - 전투력 2배 상태로 압도
  - 단, 1시간 후 기력 소진
```

### 대인 전투 전략
```
■ vs 근접 전사
  - 거리 유지 필수
  - 환술로 시야 차단 후 도주
  - 절대 근접전 허용하지 말 것

■ vs 원거리 딜러
  - 분신으로 공격 분산
  - 매혹술로 무력화 시도
  - 환술로 조준 방해

■ vs 탱커
  - 시간 끌지 말고 무시
  - 매혹술 통하지 않음
  - 후방 딜러 노리기

■ vs 마법사
  - 환술 vs 마법 대결
  - 정신력 싸움으로 승부
  - 불 속성 마법은 절대 회피

■ vs 암살자
  - 가장 위험한 상대
  - 환술 간파 가능성 높음
  - 분신으로 어그로 분산 필수
```

### 보스전 역할
```
■ 보스전 포지션
  - 후방 서포터
  - 직접 딜링 X
  - 디버프 + 아군 생존 지원

■ 주요 역할
  1. 보스 패턴을 환술로 교란
  2. 아군에게 회피 버프 제공
  3. 보스 어그로를 분신으로 분산
  4. 위급한 아군 매혹술로 보스 주의 끌기

■ 보스별 대응
  - 화염 보스: 극상성, 참여 비추천
  - 물리 보스: 환술 효과 최대
  - 마법 보스: 정신력 대결, 보통
  - 다수 보스: 광역 환술로 최적화
```
