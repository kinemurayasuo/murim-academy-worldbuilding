# 주요 인물 설정 및 강함 관계도

## 👑 천반 (天班) - 최상위 천재들

### 1위: 소요봉 (逍遙峰) ⚔️
- **소속**: 검신검파
- **학년**: 3학년
- **경지**: 화경 후기 (18세에 도달, 천재 중의 천재)
- **무공**:
  - 천검무극공(天劍無極功) 7단계
  - 구천검법(九天劍法) 완성
  - 독자 창조: 일검파천(一劍破天)
- **특수능력**: 검심통명(劍心通明) - 검의 의지를 읽는 능력
- **재능등급**: S급
- **성격**: 온화하지만 단호함, 정의감 강함
- **목표**: 조부를 넘어서는 검신이 되기
- **약점**: 지나친 완벽주의, 동료에 대한 책임감
- **외모**: 준수한 외모, 은빛 머리, 검같은 눈빛
- **별명**: "검의 황태자"

### 2위: 진아란 (秦雅蘭) 🌙
- **소속**: 무소속 (가문 배경 불명)
- **학년**: 3학년
- **경지**: 화경 후기 (정체불명의 수련법)
- **무공**:
  - 천라만상공(天羅萬象功) - 모든 무공 모방 가능
  - 환영보(幻影步) - 잔상을 남기는 신법
  - 천라수(天羅手) - 천 가지 변화의 수법
- **특수능력**: 무공모방(武功模倣) - 한 번 본 무공을 즉시 재현
- **재능등급**: S급 (특수)
- **성격**: 신비롭고 과묵함, 감정 표현 적음
- **목표**: 자신의 과거를 찾는 것
- **비밀**: 기억상실, 과거 10년 기억 없음
- **외모**: 흑발, 달처럼 창백한 피부, 보랏빛 눈동자
- **별명**: "달의 마녀"

- **특수능력**: 혈기조종(血氣操縱) - 자신과 적의 혈기 통제
- **재능등급**: A급
- **성격**: 냉혹하지만 의리있음, 오만함
- **목표**: 부친(혈천마제)을 넘어 진정한 마제 되기
- **갈등**: 사파임에도 정파 친구들 존재
- **외모**: 붉은 눈동자, 검은 머리에 붉은 끝자락
- **별명**: "혈마검성"

## ⚔️ 강함 관계도

### 절대 최강 (신화급)
```
독고무적 (교장) ≥ 천마 ≥ 검신 허천명
```

### 최상위 (천인급)
```
혈천마제 > 태극진인 송무극 ≈ 현담신승
```

### 상위권 (대종사급)
```
강천 > 매화검선 엽청운 ≈ 빙심검존 설무량 > 기타 장문들
```

### 천재 학생 순위
```
1. 소요봉 (화경 후기)
2. 진아란 (화경 후기, 능력 특수)
3. 혈무영 (화경 중기, 마공)
4. 운무백 (화경 중기, 내공)
5. 설련화 (화경 초기, 2학년 최강)
6. 진매화 (화경 초기)
7. 허공 (화경 초기, 방어 최강)
8. 남궁진 (화경 초기)
9. 당청아 (화경 초기, 독술)
10. 검무명 (화경 초기, 검술 특화)
```

### 특수 대결 관계
- **소요봉 vs 진아란**: 현재 무승부 (3전 3무)
- **소요봉 vs 혈무영**: 소요봉 우세 (5전 4승 1패)
- **설련화 vs 진매화**: 설련화 우세 (2전 1승 1무)
- **허공 vs 검무명**: 검무명 우세 (공격력 차이)

## 🔥 주요 갈등 관계

### 삼각관계
- 소요봉 ← 진매화 → (짝사랑)
- 소요봉 ↔ 진아란 (미묘한 감정)
- 혈무영 → 진아란 (짝사랑, 거절당함)

### 라이벌 관계
- 소요봉 ↔ 남궁진 (친구이자 경쟁자)
- 진아란 ↔ 설련화 (여성 최강 다툼)
- 혈무영 ↔ 허공 (정사 이념 충돌)

### 숙적 관계
- 소요봉 가문 ↔ 혈마교 (조부가 혈마교에게 중상)
- 허공 ↔ 명부 (소림사와 명부는 원수)

### 친구 관계
- 소요봉 - 남궁진 - 운무백 (정파 삼인조)
- 혈무영 - 검무명 - 홍소걸 (이단 삼인조)
- 진아란 - 설련화 (경쟁 속 인정)

## 📈 성장 잠재력

### 무한 성장형
- **진아란**: 무공모방 능력으로 무한 진화 가능
