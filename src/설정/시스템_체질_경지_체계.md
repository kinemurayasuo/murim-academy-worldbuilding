## 🧬 사상의학 체질 시스템

### 4대 체질

#### 1. 태양인 (太陽人) - 5%

**신체 특징**:
- 상체 발달, 하체 약함
- 폐 강함, 간 약함
- 열 체질, 땀 많음
- 목덜미 굵고 허리 가늠

**성격 특성**:
- 카리스마, 리더십
- 추진력 강함
- 독단적, 자존심 강함
- 창의적, 진취적

**무공 적성**:
- ✓ 강력한 일격 기술
- ✓ 패왕계 권법
- ✓ 폭발적인 힘
- ✗ 지구전 약함
- ✗ 섬세한 제어 어려움

**대표 무공**:
- 패왕권, 천둥벽력장
- 맹호출림, 폭렬신공

**약점**: 지구력 부족, 하체 약함

---

#### 2. 태음인 (太陰人) - 50%

**신체 특징**:
- 상체 약함, 하체 발달
- 간 강함, 폐 약함
- 땀 적음, 살찌기 쉬움
- 허리 굵고 목덜미 가늠

**성격 특성**:
- 침착, 신중함
- 끈기 있음
- 내향적, 계획적
- 지구력 강함

**무공 적성**:
- ✓ 내공 축적형
- ✓ 지구전
- ✓ 방어 기술
- ✓ 축적형 필살기
- ✗ 순발력 떨어짐

**대표 무공**:
- 북명신공, 대지진기
- 철벽방어, 축지법

**강점**: 내공량 최대, 지구력

---

#### 3. 소양인 (少陽人) - 30%

**신체 특징**:
- 가슴 발달, 엉덩이 약함
- 비장 강함, 신장 약함
- 활동적, 날씬함
- 상체 넓고 하체 좁음

**성격 특성**:
- 활발, 사교적
- 순발력 좋음
- 변덕, 다혈질
- 빠른 판단

**무공 적성**:
- ✓ 속도형 무공
- ✓ 경공술
- ✓ 연속기
- ✓ 암기술
- ✗ 지속력 약함
- ✗ 방어 취약

**대표 무공**:
- 섬전보법, 신속검
- 난타권, 연환퇴

**강점**: 최고 속도, 순발력

---

#### 4. 소음인 (少陰人) - 15%

**신체 특징**:
- 엉덩이 발달, 가슴 약함
- 신장 강함, 비장 약함
- 차가운 체질, 소식
- 하체 안정, 상체 약함

**성격 특성**:
- 섬세, 예민함
- 정확성 높음
- 소심, 조심스러움
- 분석적, 완벽주의

**무공 적성**:
- ✓ 정밀 제어
- ✓ 독침/암기
- ✓ 섬세한 검술
- ✓ 치유/의술
- ✗ 폭발력 부족
- ✗ 체력 약함

**대표 무공**:
- 침술, 섬세검법
- 독공, 정밀 암기

**강점**: 최고 정밀도, 제어력

## 🌟 무공 경지 체계

### 9대 경지

#### 1. 입문경 (入門境)
- **전투력**: 100~999
- **설명**: 무공 처음 입문
- **특징**: 기초 초식, 내공 미미
- **기간**: 1~3년

#### 2. 후천경 (後天境)
- **전투력**: 1,000~4,999
- **설명**: 후천적 수련으로 도달
- **특징**: 기본 초식 구사, 약한 내공
- **기간**: 5~10년

#### 3. 선천경 (先天境)
- **전투력**: 5,000~19,999
- **설명**: 선천지기 깨달음
- **특징**: 내공 활용, 무공 자유 구사
- **기간**: 15~20년
- **학원 평균**: 여기

#### 4. 화경 (化境)
- **전투력**: 20,000~49,999
- **설명**: 무공이 경지에 도달
- **특징**: 기술 변화 자유, 창조 가능
- **기간**: 25~30년
- **학원 상위권**: 여기

#### 5. 절정 (絶頂)
- **전투력**: 50,000~99,999
- **설명**: 절정고수
- **특징**: 검기/장기 발현, 일류 고수
- **기간**: 35~40년
- **학원 1등**: 여기 입문

#### 6. 현경 (玄境)
- **전투력**: 100,000~499,999
- **설명**: 오묘한 경지
- **특징**: 기운 외방, 자연과 합일
- **기간**: 50년+
- **교사급**: 여기

#### 7. 종사 (宗師)
- **전투력**: 500,000~999,999
- **설명**: 한 분야의 종사
- **특징**: 독자 무공 창조, 제자 양성
- **기간**: 70년+
- **문파 장문**: 여기

#### 8. 대종사 (大宗師)
- **전투력**: 1,000,000~9,999,999
- **설명**: 전설의 경지
- **특징**: 천지와 소통, 자연재해급
- **기간**: 100년+
- **맹주급**: 여기

#### 9. 천인합일 (天人合一)
- **전투력**: 10,000,000+
- **설명**: 하늘과 하나 됨
- **특징**: 세계 법칙 이해, 신의 경지
- **기간**: 평생
- **EX급**: 여기

---

### 경지별 특징

```
천인합일 (EX급)
    ↑ 법칙 이해의 벽
대종사 (SSS급)
    ↑ 전설의 벽
종사 (SS급)
    ↑ 창조의 벽
현경 (S급)
    ↑ 외방의 벽
절정 (A급) ← 학원 1등
    ↑ 검기의 벽
화경 (B급) ← 학원 상위
    ↑ 변화의 벽
선천경 (C~D급) ← 학원 평균
    ↑ 선천의 벽
후천경 (E급)
    ↑ 입문의 벽
입문경 (F급)
```

## 💎 특수 체질 목록

### 천부적 체질 (선천)

#### 1. 천무지체 (天武之體)
- **효과**: 모든 무공 습득 속도 10배
- **특징**: 무공 천재, 보기만 해도 배움
- **약점**: 특정 무공 극한 어려움
- **희귀도**: 천년에 1명

#### 2. 순음지체 (純陰之體)
- **효과**: 음기 무효, 음공 천재
- **특징**: 빙한 무공 특화, 열 약함
- **보유자**: 주로 여성
- **희귀도**: 백년에 1명

#### 3. 순양지체 (純陽之體)
- **효과**: 양기 무효, 양공 천재
- **특징**: 화염 무공 특화, 한기 약함
- **보유자**: 주로 남성
- **희귀도**: 백년에 1명

#### 4. 선천도체 (先天道體)
- **효과**: 도술 천재, 자연 친화
- **특징**: 도교 무공 특화
- **희귀도**: 오백년에 1명

#### 5. 금강불괴체 (金剛不壞體)
- **효과**: 방어력 극대화, 타격 무효
- **특징**: 외공 최강, 속도 느림
- **희귀도**: 백년에 1명

#### 6. 천생체마 (天生體魔)
- **효과**: 마공 천재, 마기 친화
- **특징**: 마교 무공 특화, 정기 거부
- **위험**: 주화입마 위험
- **희귀도**: 천년에 1명

### 후천적 체질 (수련/돌연변이)

#### 7. 백독불침지체 (百毒不侵之體)
- **획득**: 독 수련 극한
- **효과**: 모든 독 무효
- **부작용**: 일반 음식 맛없음

#### 8. 천의무봉지체 (天衣無縫之體)
- **획득**: 의술 극한 수련
- **효과**: 자가 치유 능력
- **특징**: 수명 연장

#### 9. 영체질 (靈體質)
- **선천**: 귀신 보임
- **효과**: 영혼과 소통
- **위험**: 빙의 위험

#### 10. 검심일체 (劍心一體)
- **획득**: 검도 극한
- **효과**: 검과 하나 됨
- **특징**: 검기 자유 제어

## 📊 9명 주요 캐릭터 체질 배정

### 강아란
- **체질**: 소음인
- **특징**: 섬세하고 정밀한 검술
- **적성**: 완벽한 제어, 정확성
- **경지**: 절정 입문

### 혈소연
- **체질**: 태음인
- **특징**: 지구력, 묵직한 힘
- **적성**: 내공 축적, 방어
- **경지**: 절정 입문

### 설무연
- **체질**: 소양인
- **특징**: 빠르고 경쾌함
- **적성**: 속도, 경공
- **경지**: 화경 정점

### 소하린
- **체질**: 소음인 + 천의무봉지체
- **특징**: 섬세한 치유
- **적성**: 의술, 정밀 제어
- **경지**: 화경 중급

### 진대식
- **체질**: 태양인
- **특징**: 폭발적인 힘
- **적성**: 강한 일격
- **경지**: 화경 중급

### 백서연
- **체질**: 소음인
- **특징**: 분석적, 정밀함
- **적성**: 전략, 계산
- **경지**: 화경 초급

### 흑영
- **체질**: 태음인
- **특징**: 지속력, 인내
- **적성**: 암살, 지구전
- **경지**: 화경 정점

### 장미설
- **체질**: 소양인 + 백독불침지체
- **특징**: 빠른 조리, 독
- **적성**: 독술, 요리
- **경지**: 화경 초급

### 운소아
- **체질**: 소양인
- **특징**: 운 좋음, 가벼움
- **적성**: 회피, 행운
- **경지**: 선천경
