# 특수 능력 계열

## 📋 개요

**계열**: 특수 능력 (特殊能力)
**분류**: 혈통, 체질, 각성
**특징**: 선천적 or 후천적 획득
**희귀도**: 극히 드묾

---

## ⭐ 등급 체계

### SSS급 - 신화 능력
**발현율**: 0.0001%
**효과**: 세계 법칙 수준

### SS급 - 전설 능력
**발현율**: 0.001%
**효과**: 자연 법칙 조작

### S급 - 절정 능력
**발현율**: 0.01%
**효과**: 물리 법칙 초월

### A급 - 고급 능력
**발현율**: 0.1%
**효과**: 특수 기능

### B급 - 중급 능력
**발현율**: 1%
**효과**: 강화 효과

## 🌟 SSS급 특수 능력

### 1. 시공 조작 (時空操作)
**등급**: SSS
**유형**: 각성
**발현 조건**: 극한 상황 + 천부적 재능

**효과**:
- 시간 조작 (정지, 가속, 역행)
- 공간 조작 (이동, 왜곡, 생성)
- 차원 이동
- 인과율 무시

**제한**:
- 정신력 막대한 소모
- 사용 시 수명 감소
- 1일 1회

**부작용**:
- 시간 감각 상실
- 현실 인식 왜곡

---

### 2. 완전 재생 (完全再生)
**등급**: SSS
**유형**: 혈통
**발현**: 특수 혈통 보유

**효과**:
- 모든 부상 재생
- 절단된 팔다리 재생
- 노화 무효
- 불사에 가까움

**재생 속도**:
- 경상: 1초
- 중상: 10초
- 치명상: 1분
- 절단: 10분

**약점**:
- 머리 파괴 시 사망
- 심장 + 머리 동시 파괴 시 불가

---

### 3. 절대 예지 (絶對豫知)
**등급**: SSS
**유형**: 각성
**발현**: 정신력 극한 + 각성

**효과**:
- 미래 예지 (최대 1시간)
- 확률 계산 100%
- 모든 공격 사전 인지
- 최적 행동 파악

**제한**:
- 정신력 소모 극심
- 과사용 시 정신 붕괴
- 연속 사용: 최대 10분

## 🎯 특수 능력 조합

### 능력 + 능력
```
빙설 체질 + 화염 체질 = 음양 체질 (SS)
- 불가능에 가까움
- 성공 시 최강
```

### 능력 + 무공
```
뇌전 체질 + 삼천뇌동 = 뇌신 강림 (SS+)
- 번개 그 자체
- 속도 극한
```

### 능력 + 내공
```
완전 재생 + 불멸진기 = 진정한 불사 (SSS)
- 죽지 않음
- 늙지 않음
```

## 💡 능력 각성 방법

### 선천적 각성
- 태어날 때부터 발현
- 혈통 or 체질
- 변경 불가능

### 후천적 각성
- 극한 상황
- 생사의 경계
- 강렬한 감정

### 수련을 통한 각성
- 20년+ 수련
- 특정 경지 도달
- 깨달음 필요

### 약물을 통한 각성
- 영약 복용
- 위험성 높음
- 성공률 10%

## 🔄 능력 진화 시스템

### 자연 진화
```
B급 능력
→ 수련 (10년)
→ A급 능력
→ 수련 (20년)
→ S급 능력
```

### 각성 진화
```
일반 체질
→ 극한 상황
→ 각성
→ 특수 능력 발현
```

### 융합 진화
```
능력 A + 능력 B
→ 극도로 위험
→ 성공 시 상위 능력
→ 실패 시 사망
```

## 🌀 능력 vs 무공

### 능력 장점
- 선천적 강함
- 수련 불필요 (기본)
- 독특한 효과
- 대체 불가능

### 무공 장점
- 누구나 배울 수 있음
- 수련으로 강화
- 다양한 변형
- 체계적

### 최강의 조합
```
특수 능력 (SSS)
+ 절정 무공 (SSS)
+ 최강 내공 (SSS)
= 무림 최강자
```
