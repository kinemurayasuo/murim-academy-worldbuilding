- 검기 사거리: 30m

**4단계 - 검기 분할**
- 하나의 검기를 여러 개로 분할
- 동시 공격 가능
- 최대 10개 분할

**5단계 - 검기 변화**
- 검기의 속성 변환 가능
- 화/빙/뇌 속성 부여
- 위력 500% 증가

**6단계 - 검기 융합**
- 여러 검기를 하나로 압축
- 극대 위력 집중
- 위력 800% 증가

**7단계 - 검심 통명**
- 검과 일체화
- 검의 의지로 전투 가능
- 위력 1000% 증가

**8단계 - 검역 형성**
- 검의 영역 전개
- 반경 50m 내 검 지배
- 상대 검 무력화 가능

**9단계 - 검신 강림**
- 검의 신이 빙의
- 일시적 신급 전투력
- 부작용: 3일간 무력화

**10단계 - 무극 경지**
- 모든 검법의 극의
- 천하무적의 검술
- 현존 달성자: 없음

#### 비기 초식
- **일검파천** (一劍破天): 하늘을 가르는 검기
- **만검귀일** (萬劍歸一): 만 개의 검을 하나로
- **검역무쌍** (劍域無雙): 검의 영역 최대 전개

## 📖 수련 시 주의사항

### 일반 주의사항
1. **무리한 수련 금지**: 주화입마 위험
2. **단계 준수**: 단계 뛰어넘기 금지
3. **교수 감독**: 고급 무공은 반드시 감독하 수련
4. **체질 확인**: 자신의 체질에 맞는 무공 선택

### 위험 신호
- 진기 역류: 즉시 수련 중단
- 혈기 비등: 냉각 시간 필요
- 환각 증상: 주화입마 전조
- 극심한 통증: 경맥 손상 가능

### 응급 처치
1. 수련 즉시 중단
2. 약왕전 방문
3. 교수에게 보고
4. 1주일 수련 금지
