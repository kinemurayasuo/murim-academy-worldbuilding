# 주인공 공략법

## 💝 공략 시스템 설명

### 호감도 단계
```
Lv.0: 모르는 사이 (0-20)
Lv.1: 아는 사이 (21-40)
Lv.2: 친구 (41-60)
Lv.3: 친한 친구 (61-80)
Lv.4: 소중한 사람 (81-95)
Lv.5: 연인 (96-100)
```

### 호감도 확인 방법
```
AI 앱 "무림 인연":
- 상대방 호감도 표시
- 현재 관계도
- 호감도 상승 팁
- 이벤트 알림
```

## 1️⃣ 강아란 공략법

### 기본 정보
```
난이도: ★★★★★ (최상)
타입: 완벽주의자
좋아하는 것: 계획, 효율, 성장
싫어하는 것: 지각, 불성실, 무계획
```

### 호감도 상승 이벤트

#### 초반 (호감도 0-40)
```
이벤트 1: 스터디 그룹
- 시기: 1학년 5월
- 장소: 도서관
- 조건: 성적 상위 30%
- 선택지:
  └─ "같이 공부할래?" (+5)
  └─ "도와줘" (-5)
  └─ "내가 도와줄게" (+10) ✓

이벤트 2: 일정 관리
- 시기: 항상
- 조건: 계획표 작성
- 효과:
  └─ 계획표 공유 (+3/일)
  └─ 계획대로 실행 (+5/주)

이벤트 3: 새벽 수련
- 시기: 매일 05:00
- 장소: 수련장
- 조건: 일찍 일어나기
- 선택지:
  └─ "같이 수련할래?" (+5)
  └─ 묵묵히 따라하기 (+10) ✓
  └─ "너무 일찍인데..." (-10)
```

#### 중반 (호감도 41-80)
```
이벤트 4: 약점 발견
- 시기: 1학년 여름
- 장소: 교실
- 조건: 호감도 50+
- 내용: 강아란이 고민 상담
- 선택지:
  └─ "괜찮아?" (+5)
  └─ "도와줄게" (+15) ✓
  └─ "혼자 해결해" (-20)

이벤트 5: 대련 연습
- 시기: 호감도 60+
- 장소: 대련장
- 조건: 전투력 30,000+
- 선택지:
  └─ "같이 연습하자" (+10)
  └─ "내가 상대해줄게" (+20) ✓
  └─ "너무 강해..." (-10)

이벤트 6: 축제 준비
- 시기: 가을 축제
- 조건: 호감도 70+
- 선택지:
  └─ "내가 도와줄게" (+10)
  └─ "같이 하자" (+20) ✓
  └─ "너 혼자 해" (-30)
```

#### 후반 (호감도 81-100)
```
이벤트 7: 고백 전 단계
- 시기: 호감도 85+
- 장소: 옥상 (밤)
- 조건: 특별 이벤트 5개 이상
- 내용: 진심 대화
- 선택지:
  └─ "항상 고마워" (+15)
  └─ "너는 특별해" (+25) ✓
  └─ "우린 친구지" (-50)

이벤트 8: 고백 이벤트
- 시기: 호감도 95+
- 장소: 벚꽃 아래
- 조건: 모든 조건 충족
- 선택지:
  └─ "좋아해" (+30) → 연인
  └─ "사랑해" (+50) → 연인 (True End)
  └─ "친구로..." (-100) → Bad End
```

### 공략 팁
```
필수 조건:
✓ 성실함 유지 (지각 금지)
✓ 계획적 행동
✓ 성적 상위 유지
✓ 매일 새벽 수련
✓ 호감도 꾸준히 상승

금기 사항:
✗ 지각
✗ 불성실
✗ 계획 없는 행동
✗ 게으름
✗ 거짓말
```

### 특별 엔딩
```
True Ending: "완벽한 파트너"
- 조건: 호감도 100 + 전투력 50,000+
- 내용: 같이 정점 도달
- 보상: 특별 스킬 "완벽한 호흡"

Good Ending: "소중한 사람"
- 조건: 호감도 96+
- 내용: 연인 관계
- 보상: 호감도 유지 쉬움

Normal Ending: "친한 친구"
- 조건: 호감도 80-95
- 내용: 친구 유지

Bad Ending: "서먹한 사이"
- 조건: 호감도 80 미만
- 내용: 관계 악화
```
