# 게임 시스템 요소

## 🎮 RPG 시스템

### 캐릭터 생성
```
1단계: 이름 입력
- 성씨 선택
- 이름 자유 입력
- 별명 설정

2단계: 외모 커스터마이징
- 얼굴 (50종)
- 헤어스타일 (100종)
- 체형 (10종)
- 목소리 (30종)

3단계: 초기 스탯 배분
- 총 포인트: 100
- 힘, 민첩, 체력, 지능, 정신
- 최소: 5, 최대: 30

4단계: 출신 배경 선택
- 명문가 출신
  └─ 초기 자금 +50%
  └─ 인맥 +20%
  └─ 기대감 압박 +30%

- 평민 출신
  └─ 성장률 +20%
  └─ 근성 +30%
  └─ 초기 자금 -30%

- 고아 출신
  └─ 성장률 +30%
  └─ 잠재력 +20%
  └─ 인맥 -50%

5단계: 특수 재능 선택 (1개)
- 검술 천재: 검술 습득 +50%
- 내공 천재: 내공 성장 +50%
- 전략가: 전투 시 버프
- 행운아: 행운 +30
- 노력파: 모든 수련 +20%
```

## 📊 스탯 시스템

### 기본 스탯 (성장 가능)
```
힘 (力):
- 물리 공격력
- 무기 사용
- 운반 능력
- 상승: 체력 훈련, 무기 수련

민첩 (敏):
- 공격 속도
- 회피율
- 경공 능력
- 상승: 경공 수련, 대련

체력 (體):
- 최대 HP
- 방어력
- 지구력
- 상승: 체력 단련, 실전

지능 (智):
- 무공 이해도
- 습득 속도
- 전략 수립
- 상승: 이론 학습, 독서

정신 (精):
- 최대 MP (내공)
- 정신 공격 저항
- 집중력
- 상승: 명상, 내공 수련
```

### 전투 스탯
```
전투력:
- 종합 능력치
- 자동 계산
- 공개 가능/불가 선택

내공:
- 무공 사용 자원
- 회복: 휴식, 명상
- 최대치 증가: 내공 수련

검기:
- 검술 위력 배율
- 검사 전용
- 상승: 검술 수련

장력:
- 장법 위력 배율
- 장법 사용자
- 상승: 장법 수련

경공:
- 이동 속도
- 점프력
- 공중 제어
- 상승: 경공 수련
```

### 숨겨진 스탯
```
행운:
- 크리티컬 확률
- 아이템 드롭률
- 이벤트 발생
- 상승: 랜덤, 특수 아이템

매력:
- NPC 호감도 상승
- 할인율
- 이벤트 선택지 추가
- 상승: 외모 관리, 행동

인맥:
- 정보 접근성
- 거래 편의
- 퀘스트 추가
- 상승: 관계 형성

명성:
- 사회적 영향력
- 특수 지역 접근
- VIP 대우
- 상승: 업적 달성
```

## 💰 경제 시스템

### 화폐
```
기본 화폐: 냥
- 구리 냥 (동전)
- 은 냥 (은화)
- 금 냥 (금화)

환율:
- 구리 100 = 은 1
- 은 100 = 금 1

특수 화폐:
- 무림 포인트 (이벤트 보상)
- 학점 (학원 내 화폐)
- 명성 포인트 (상점 할인)
```

### 수입원
```
고정 수입:
- 학원 장학금: 월 10만냥
- 아르바이트: 시간당 5천냥
- 용돈: 주 5만냥

변동 수입:
- 대련 상금: 1만~100만냥
- 퀘스트 보상: 5만~500만냥
- 아이템 판매: 시세
- 이벤트 상금: 1억냥+
```

### 지출
```
필수:
- 식비: 월 30만냥
- 수련 재료: 월 50만냥
- 장비 수리: 월 20만냥

선택:
- 무기 구매: 100만~10억냥
- 비급 구매: 500만~50억냥
- 패션: 10만~1000만냥
- 간식: 1만~10만냥
```

## ⚔️ 전투 시스템

### 전투 방식
```
액션 RPG:
- 실시간 전투
- 스킬 쿨타임
- 콤보 시스템
- 회피/패리/가드

자동 전투:
- AI 전투 가능
- 효율: 수동의 70%
- 편의성 높음
```

### 대련 시스템
```
종류:
1. 일반 대련
   - 경험치 획득
   - 스킬 숙련도 상승
   - 부상 없음

2. 실전 대련
   - 경험치 2배
   - 부상 위험
   - 실전 경험 획득

3. 랭킹 대련
   - 순위 변동
   - 보상 획득
   - 명성 상승

4. 팀 대련
   - 3vs3, 5vs5
   - 팀워크 훈련
   - 팀 포인트 획득
```

### 전투 보상
```
승리 보상:
- 경험치
- 전투력 상승
- 스킬 숙련도
- 아이템 (확률)
- 명성 포인트

패배:
- 경험치 (승리의 30%)
- 교훈 획득
- 약점 분석 리포트
```
