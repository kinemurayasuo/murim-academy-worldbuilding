# 의사 (醫士) 직업

## 📋 개요

**직업명**: 의사 (醫士)
**주 무기**: 의술, 약, 침
**특징**: 생명 구원, 치료, 보조
**대표 인물**: 화타재세, 약왕, 신의

---

## ⭐ 직급 체계

### 전설
- **신의** (神醫) - 신의 의술
- **약왕** (藥王) - 약의 왕
- **의선** (醫仙) - 의술의 선인

### 고급
- **명의** (名醫) - 이름난 의사
- **의협** (醫俠) - 의술의 협객
- **의사** (醫士) - 의술의 무사

### 중급
- **견습 의사** - 수련 중
- **초보 의사** - 입문

---

## 💪 직업 특성

### 장점
1. **생명 구원**: 죽어가는 자 살림
2. **높은 수요**: 항상 필요함
3. **존경받음**: 사회적 지위 높음
4. **안정적**: 수입 보장
5. **보람**: 생명 살리는 기쁨

### 단점
1. **전투 약함**: 직접 싸우기 어려움
2. **긴 수련**: 배우는 데 오래 걸림
3. **책임감**: 실수 시 생명 위험
4. **과로**: 항상 바쁨
5. **스트레스**: 정신적 부담

## 🎪 코믹 요소

### 의사의 일상
```
아침: "오늘 환자 50명..."
→ 진료 시작

점심: "밥 먹을 시간이..."
→ 응급 환자 도착
→ 점심 거름

저녁: "이제 끝!"
→ 밤 응급 환자
→ 밤샘 수술

새벽: "...언제 자지?"
```

### 의사의 고민
1. **과로**
   - "하루 20시간 일함"
   - "잠이 부족해..."
   - "커피가 밥이야"

2. **환자 폭주**
   - "대기 100명..."
   - "언제 다 보지"
   - "분신술 배울까?"

3. **응급 환자**
   - "지금 밥 먹는데..."
   - "막 자려는데..."
   - "휴가인데..."
   - → 전부 취소
