# 권법 계열 스킬

## 📋 개요

**계열**: 권법 (拳法)
**주 무기**: 맨손
**특징**: 강력한 타격, 직선적 공격
**대표 문파**: 소림사, 무당파, 개방

---

## ⭐ 등급 체계

### SSS급 - 신화 권법
**위력**: 산을 부숨

### SS급 - 전설 권법
**위력**: 바위를 가루로

### S급 - 절정 권법
**위력**: 쇠를 구부림

### A급 - 고급 권법
**위력**: 나무를 부러뜨림

### B급 - 중급 권법
**위력**: 벽돌 파괴

## 👊 SSS급 권법

### 1. 천지파멸권 (天地破滅拳)
**등급**: SSS
**소속**: 전설
**습득 조건**: 권의 극의 + 화경 절정

**효과**:
- 일격으로 산 파괴
- 대지 균열 생성
- 충격파 반경 1km
- 지진 유발

**기술 구성**:
```
1초: 천열권 - 하늘을 가름
2초: 지쇄권 - 대지를 부숨
3초: 천지멸 - 천지 파괴
```

**사용 제한**:
- 1일 1회
- 생명력 80% 소모
- 사용 후 1주일 전투 불가

## 🎯 권법 조합 시스템

### 속성 융합
```
화염폭렬권 + 빙백파쇄권 = 빙화양의권 (SS-)
- 화염 + 냉기 동시
- 온도차로 파괴력 3배
```

### 권법 + 내공
```
대라한권 + 용상반야공 = 나한용상권 (SSS-)
- 기술 + 힘 극대화
- 완벽한 권법
```

### 권법 + 신법
```
뇌신폭권 + 신행보 = 뇌신섬권 (S+)
- 속도 + 파괴력
```

## 💡 특수 권법 효과

### 권강 (拳罡)
- 조건: 화경 초기
- 효과: 주먹에서 진기 방출
- 사정거리: 10m

### 권의 (拳意)
- 조건: 권법 이해 극한
- 효과: 타격 없이 권압으로 공격

### 권기 (拳氣)
- 조건: 권법 숙련
- 효과: 주먹에서 기파 발사

### 권신 (拳神)
- 조건: 최고 경지
- 효과: 권법의 신이 됨

## 🔄 권법 진화 시스템

### 기본 → 고급
```
기본 권법 (B)
→ 나한권 (A)
→ 대라한권 (SS)
→ 나한금강권 (SSS)
```

### 속성 부여
```
나한권 (A)
+ 화염 내공 = 화염나한권 (S)
+ 빙설 내공 = 빙설나한권 (S)
+ 뇌전 내공 = 뇌전나한권 (S)
```
