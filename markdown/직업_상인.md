# 상인 (商人) 직업

## 📋 개요

**직업명**: 상인 (商人)
**주 특기**: 거래, 정보, 협상
**특징**: 돈 버는 능력, 인맥, 정보력
**대표 인물**: 천하제일상, 금강상회주, 만물상

---

## ⭐ 직급 체계

### 전설
- **상제** (商帝) - 상인의 황제
- **상왕** (商王) - 상인의 왕
- **천상** (天商) - 천하 최고 상인

### 고급
- **대상인** (大商人) - 큰 상인
- **상호** (商豪) - 상인 호걸
- **명상** (名商) - 이름난 상인

### 중급
- **견습 상인** - 수련 중
- **초보 상인** - 입문

---

## 💪 직업 특성

### 장점
1. **돈 버는 능력**: 최강 재력
2. **정보력**: 모든 걸 안다
3. **인맥**: 모두와 친분
4. **협상 능력**: 설득의 달인
5. **생존력**: 돈으로 해결

### 단점
1. **전투 약함**: 직접 싸우기 어려움
2. **돈 집착**: 돈에 민감
3. **신뢰 문제**: 믿기 어려움
4. **과로**: 24시간 일함
5. **스트레스**: 손익 계산
