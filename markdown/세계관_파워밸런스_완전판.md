## 🎯 재능 등급 vs 현재 실력

### 재능 등급 (잠재력)
```
EX: 세계관 최강까지 성장 가능

S: 일류고수까지 성장 가능

```
학원 1등 (강아란): 52,000 (A-)

학원 3등 (흑영): 42,000 (B+)
학원 4등 (설무연): 45,000 (B+)

※ 재능은 EX여도 현재는 학생
※ 미래에 EX급 도달 가능성이 있을 뿐

## ⚖️ 파워밸런스 원칙

### 절대 규칙
1. **EX는 진짜 최강자만**: 천년에 한 명 수준
2. **학생은 미완성**: 아무리 천재라도 A등급 한계
3. **나이 = 경험**: 젊은이는 잠재력, 노인은 경지
4. **종족 차이**: 요괴/신수는 인간보다 기본 스펙 높음
5. **성장 시간**: 하루아침에 강해지지 않음

### 밸런스 유지
- 학생들이 이기는 상대: C~B 등급
- 학생들이 고전하는 상대: A 등급
- 학생들이 도망가야 하는 상대: S 이상
- 학생들이 절대 못 이기는 상대: SS 이상

## 🎯 경지 돌파 난이도

### 벽(壁) 개념
```
후천 → 선천: ★★☆☆☆ (노력으로 가능)
선천 → 화경: ★★★☆☆ (재능 필요)
화경 → 무경: ★★★★☆ (재능 + 기연)
무경 → 현경: ★★★★★ (천재 중 극소수)
현경 → 천경: ★★★★★+ (평생 노력해도 안 되는 벽)
천경 → 신경: ★★★★★++ (천년에 한 명)
신경 → 천인합일: ★★★★★+++ (전설의 영역)
```

### 돌파 조건
```
선천경 돌파: 선천지기 개안
화경 돌파: 무공의 진수 깨달음
무경 돌파: 무의 경지 체득
현경 돌파: 현묘한 이치 통달
천경 돌파: 천지자연과의 공명
신경 돌파: 인간 한계 초월
천인합일: 천지와 하나됨
```

```
1년치 내공 = 약 100~500 전투력 상승
10년치 내공 = 약 1,000~5,000 전투력
50년치 내공 = 약 5,000~50,000 전투력
100년치 내공 = 약 10,000~100,000 전투력

※ 경지가 높을수록 내공 효율 증가
※ 같은 100년치라도 경지에 따라 전투력 차이 큼

예시:
- 선천경 100년치 = 30,000
- 화경 100년치 = 80,000
- 무경 100년치 = 200,000
- 현경 100년치 = 600,000
```

---

## ⚔️ 경지별 전투 능력

### 선천경 vs 화경
```
선천경 10명 < 화경 1명
이유: 경지 차이는 숫자로 메울 수 없음
```

### 화경 vs 무경
```
화경 5명 < 무경 1명
이유: 일류고수의 벽은 절대적
```

### 무경 vs 현경
```
무경 10명 = 현경 1명 (고전)
이유: 숫자가 많으면 현경도 위험
```

### 현경 vs 천경
```
현경 20명 < 천경 1명
이유: 전설급은 차원이 다름
```

### 천경 vs 신경
```
천경 50명 < 신경 1명
이유: 세계관 최강자는 규격외
```

## 💡 경지 수련 시간

### 평범한 재능 기준
```
입문경 → 후천경: 3~5년
후천경 → 선천경: 10~15년
선천경 → 화경: 20~30년
화경 → 무경: 30~50년
무경 → 현경: 50~100년 (대부분 실패)
현경 → 천경: 평생 (거의 불가능)
천경 → 신경: 불가능
```

### 천재 기준
```
입문경 → 후천경: 1~2년
후천경 → 선천경: 3~5년
선천경 → 화경: 5~10년
화경 → 무경: 10~20년
무경 → 현경: 20~50년
현경 → 천경: 50~100년 (소수만 성공)
천경 → 신경: 100년+ (극소수)
```

### 절대 천재 기준 (강아란급)
```
입문경 → 후천경: 1년
후천경 → 선천경: 2년
선천경 → 화경: 3~5년 ← 현재 여기
화경 → 무경: 5~10년
무경 → 현경: 10~20년
현경 → 천경: 20~50년
천경 → 신경: 50~100년 (가능성 있음)
```
