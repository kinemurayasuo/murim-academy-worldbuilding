## 💕 호감도 시스템

### 호감도 단계
```
━━━━━━━━━━━━━━━━━━━━━━━━
-100                 0                 100
  ↓                  ↓                  ↓
증오              보통              사랑
```

### 세부 단계 (11단계)

| 수치 | 단계 | 아이콘 | 설명 | 효과 |
|------|------|--------|------|------|
| -100~-80 | 증오 | 💀 | 죽이고 싶음 | 공격 가능 |
| -79~-60 | 적대 | 😡 | 매우 싫어함 | 대화 거부 |
| -59~-40 | 혐오 | 😤 | 불편함 | 협력 불가 |
| -39~-20 | 불편 | 😒 | 피하고 싶음 | 최소 접촉 |
| -19~-1 | 부정적 | 😐 | 별로 안 좋음 | 냉담 |
| 0~19 | 무관심 | 😶 | 관심 없음 | 기본 대화 |
| 20~39 | 호기심 | 😯 | 궁금함 | 친해지기 시작 |
| 40~59 | 호감 | 😊 | 좋아함 | 친구 |
| 60~79 | 신뢰 | 🤝 | 믿음 | 든든한 동료 |
| 80~99 | 애정 | 💕 | 사랑 직전 | 연인 준비 |
| 100 | 사랑 | ❤️ | 진심 | 연인/결혼 |

## 📈 호감도 변화 요인

### 상승 요인
```
일상:
- 대화 (+1~3)
- 같이 식사 (+2~5)
- 선물 (+5~20)
- 칭찬 (+3~7)
- 도움 (+5~15)

이벤트:
- 위기 구출 (+20~40)
- 비밀 공유 (+15~25)
- 데이트 성공 (+10~30)
- 고백 성공 (+50)
- 특별 이벤트 (+30~60)

특수:
- 상성 좋음 (×1.5)
- 타이밍 완벽 (×2.0)
- 캐릭터 취향 저격 (×3.0)
```

### 하락 요인
```
일상:
- 무시 (-2~5)
- 약속 어김 (-10~20)
- 비밀 누설 (-30~50)
- 거짓말 (-15~30)

심각:
- 배신 (-50~80)
- 위험 노출 (-40~60)
- 소중한 것 파괴 (-60~90)
- 생명 위협 (-100, 즉시 증오)

특수:
- 상성 나쁨 (×2.0 하락)
- 타이밍 최악 (×3.0 하락)
- 트라우마 자극 (-100 직행)
```

## 💔 삼각관계 & 갈등

### 라이벌 구도
```
강아란 ←경쟁→ 혈소연
"1등 자리를 두고..."

설무연 ←친구→ 운소아
"4차원 시너지"

백서연 ←지식→ 장미설
"책 vs 실전(요리)"

소하린 ←힐러→ 진대식
"치유와 식욕의 공생"

흑영 (단독)
"누구에게도 의지 안 함"
```

### 호감도 충돌
```
동시에 여러 캐릭터 호감도 80 이상:
→ 질투 이벤트 발생

예시:
강아란(호감 85) + 혈소연(호감 80)
→ "선택의 시간" 이벤트
→ 한 명 선택 시 다른 한 명 호감도 -30

해결책:
- 하렘 루트: 모두 호감 100 (초고난이도)
- 단일 루트: 한 명만 집중
- 친구 루트: 모두 60~79 유지
```
