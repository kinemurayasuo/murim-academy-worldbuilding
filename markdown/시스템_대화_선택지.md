## 💬 대화 시스템 기본

### 대화 구조
```
┌─────────────────────────┐
│  [캐릭터 이름]          │
├─────────────────────────┤
│  [캐릭터 표정 이모티콘] │
│                         │
│  "대사 내용..."         │
│                         │
│  [감정 상태 표시]       │
└─────────────────────────┘

선택지:
1. [선택지 1] (호감 +5) 😊
2. [선택지 2] (호감 -3) 😐
3. [선택지 3] (호감 +10) 💕
4. [침묵] (호감 0)
```

### 선택지 타입

#### A. 호감도 변화형
```
직접 영향:
✓ 칭찬: +3~10
✓ 공감: +5~15
✓ 도움 제안: +8~20
✗ 무시: -5~15
✗ 비난: -10~30
✗ 거짓말: -20~50
```

#### B. 스탯 변화형
```
능력치 영향:
- 지혜로운 선택: 지능 +1
- 용감한 선택: 용기 +1
- 친절한 선택: 매력 +1
- 전략적 선택: 전술 +1
```

#### C. 스토리 분기형
```
루트 변경:
→ 정파 루트
→ 사파 루트
→ 중립 루트
→ 하렘 루트
→ 솔로 루트
```

## 🎭 캐릭터별 대화 패턴

### 강아란 (완벽주의자)

#### 일상 대화
```
━━━━━━━━━━━━━━━━━━━━━━━━
강아란: "...늦었습니다. 3분 12초."
━━━━━━━━━━━━━━━━━━━━━━━━

선택지:
1. "죄송합니다. 다음엔 더 일찍 올게요"
   → 호감 +8, 신뢰 +5 ✓
   → 아란: "...당연한 말씀입니다."

2. "고작 3분인데 뭐가 문제죠?"
   → 호감 -20, 신뢰 -15 ✗
   → 아란: "...실망입니다." (차갑게)

3. "시계를 확인하지 못했어요"
   → 호감 +3
   → 아란: "...다음부터 확인하세요."

4. "아란씨도 완벽하지 않잖아요?"
   → 호감 -25, 분노 ✗✗
   → 아란: "...더 이상 말하지 마세요."
```

#### 이벤트 대화 (호감 60+)
```
━━━━━━━━━━━━━━━━━━━━━━━━
강아란: "...99점을 받았습니다."
(방에 틀어박힌 채, 차가운 목소리)
━━━━━━━━━━━━━━━━━━━━━━━━

선택지:
1. "99점도 대단한 거예요"
   → 호감 -10 ✗
   → 아란: "...당신은 이해 못 합니다."

2. "완벽하지 않아도 괜찮아요"
   → 호감 -30 ✗✗
   → 아란: "...나가주세요." (화남)

3. [조용히 곁에 앉기]
   → 호감 +25, 신뢰 +20 ✓✓
   → 아란: "...당신은, 이상하네요."

4. "1점이 아쉬웠군요. 어디서 틀렸어요?"
   → 호감 +35, 신뢰 +25, 특별 이벤트 발생 ✓✓✓
   → 아란: "...당신은, 처음으로 제 마음을 이해하는 것 같아요."
```

### 혈소연 (무표정 사고뭉치)

#### 사고 발생 대화
```
━━━━━━━━━━━━━━━━━━━━━━━━
혈소연: "...별일 아니에요."
(뒤에 건물 무너짐)
━━━━━━━━━━━━━━━━━━━━━━━━

선택지:
1. "별일 아니라니! 건물이 무너졌잖아!"
   → 호감 -25 ✗
   → 소연: "...시끄러워요."

2. "괜찮아요? 다친 데는 없어요?"
   → 호감 +20, 친밀 +15 ✓✓
   → 소연: "...고마워요." (미세한 미소)

3. [침묵하며 수습 도와주기]
   → 호감 +30, 신뢰 +20 ✓✓✓
   → 소연: "...당신은, 안 피하네요."

4. "또 사고 쳤네요. 이제 익숙해요"
   → 호감 +15, 친밀 +10 ✓
   → 소연: "...그렇군요." (조금 편해짐)
```

#### 감정 표현 대화 (호감 80+)
```
━━━━━━━━━━━━━━━━━━━━━━━━
혈소연: "...당신과 있으면, 이상해요."
(무표정이지만 귀가 빨갛게)
━━━━━━━━━━━━━━━━━━━━━━━━

선택지:
1. "어떻게 이상한데요?"
   → 호감 +10
   → 소연: "...몰라요." (고개 돌림)

2. "나도 당신과 있으면 이상해요"
   → 호감 +25, 로맨스 +20 ✓✓
   → 소연: "...그렇군요." (눈빛 부드러워짐)

3. [손을 잡기]
   → 호감 +40, 고백 루트 진입 ✓✓✓
   → 소연: "...좋아해요." (무표정)

4. "감정 표현이 서툴러서 그래요?"
   → 호감 -15 ✗
   → 소연: "...당신도 몰라요."
```

### 설무연 (4차원 천재)

```

설무연: "저 구름, 우리를 보고 웃어요!"

선택지:
1. "그냥 구름일 뿐이에요"
   → 호감 -20 ✗
   → 무연: "...재미없어요." (슬픔)

2. "정말 그런 것 같네요!"
   → 호감 +20, 친밀 +15 ✓✓
   → 무연: "헤헤~ 당신도 보이는구나!"

3. "무연이 눈에만 보이는 특별한 구름인가봐요"

   → 무연: "당신은... 제 우주예요!"

4. "무연이가 웃으니까 구름도 웃는 거예요"
   → 호감 +35, 특별 이벤트 ✓✓✓
```

## 🎯 상황별 선택지 예시

### 위기 상황

#### 전투 중 선택
```
━━━━━━━━━━━━━━━━━━━━━━━━
상황: 강적 등장, 아군 불리
━━━━━━━━━━━━━━━━━━━━━━━━

선택지:
1. "다들 도망쳐!" (안전 우선)
   → 생존률 +50%, 평판 -20
   → 소하린 호감 +15 (생명 중시)
   → 강아란 호감 -10 (도망 혐오)

2. "전략을 세우자!" (전술적 판단)
   → 생존률 +30%, 평판 +10
   → 백서연 호감 +20 (논리적)
   → 진대식 호감 -5 (배고픔)

3. "내가 막을게!" (희생정신)
   → 생존률 -30%, 평판 +50
   → 전체 호감 +25
   → 소하린 호감 +40 (걱정)

4. "흑영, 암습해!" (암살자 활용)
   → 생존률 +60%, 흑영 신뢰 +30
   → 정파 평판 -10
   → 흑영 호감 +35
```

### 로맨스 이벤트

#### 고백 받기
```
━━━━━━━━━━━━━━━━━━━━━━━━
강아란: "...당신을, 좋아합니다."
(얼굴 빨개진 채 정면 응시)
━━━━━━━━━━━━━━━━━━━━━━━━

선택지:
1. "나도 좋아해요" (즉시 수락)
   → 연인 관계 시작
   → 다른 캐릭터 루트 종료
   → 강아란 전용 엔딩 루트

2. "시간을 주세요" (보류)
   → 호감 -15, 1주일 대기
   → 다른 캐릭터 루트 유지
   → 재고백 기회 1회

3. "친구로 지내요" (거절)
   → 호감 -40, 관계 악화
   → 친구 관계로 고정
   → 로맨스 루트 영구 종료

4. "저도... 당신을 기다렸어요" (완벽한 수락)
   → 호감 +50 (150으로 증가)
   → 트루 엔딩 루트 진입
   → 특별 CG 해금
```

## 📊 선택지 시스템

### 선택지 난이도
```
난이도 표시:
😊 쉬움 - 명확한 정답
😐 보통 - 상황 판단 필요
😰 어려움 - 복잡한 선택
🤯 극악 - 정답 없는 딜레마

예시:
[😊] "좋아요" → 확실한 긍정
[😐] "생각해볼게요" → 중립
[😰] "조건부 동의" → 복잡
[🤯] "거절하지만 대안 제시" → 고난도
```

### 숨겨진 선택지
```
조건부 선택지:
- 특정 스탯 필요
- 특정 아이템 보유
- 이전 선택지 영향

예시:
━━━━━━━━━━━━━━━━━━━━
상황: 백서연이 어려운 문제로 고민 중
━━━━━━━━━━━━━━━━━━━━

기본 선택지:
1. "힘내요"
2. "도와줄게요"
3. [침묵]

숨겨진 선택지:
4. "이 이론으로 접근하면 어떨까요?"
   (지능 80+ 필요) ✨
   → 호감 +50, 특별 이벤트

5. "이 책에서 본 것 같은데..."
   (특정 책 읽기 필요) ✨✨
   → 호감 +60, 친밀도 MAX
```

### 타이밍 선택지
```
시간 제한:
⏱️ 5초: 직관 선택
⏱️ 10초: 빠른 판단
⏱️ 30초: 신중한 선택
⏱️ 무제한: 전략 수립

예시:
━━━━━━━━━━━━━━━━━━━━
⚠️ 위기 상황! (5초 제한)
━━━━━━━━━━━━━━━━━━━━

1. 막기 ⚔️
2. 피하기 🏃
3. 반격하기 ⚡
4. [시간 초과 시 자동 선택]
```

## 🎪 특수 선택지 시스템

### 능력치 체크
```
━━━━━━━━━━━━━━━━━━━━━━━━
문: 무거운 문, 여는 방법은?
━━━━━━━━━━━━━━━━━━━━━━━━

1. [힘으로 밀기] (근력 80+ 필요)
   성공: 문 열림, 시간 절약
   실패: 체력 -20, 시간 낭비

2. [기계 장치 분석] (지능 70+ 필요)
   성공: 문 해제, 경험치 +50
   실패: 함정 발동

3. [주문 시도] (내공 60+ 필요)
   성공: 마법으로 개방
   실패: 내공 -30

4. [다른 길 찾기] (항상 성공)
   시간 소모 +30분
```

### 아이템 사용 선택
```
━━━━━━━━━━━━━━━━━━━━━━━━
상황: 독에 중독된 동료
━━━━━━━━━━━━━━━━━━━━━━━━

1. [해독제 사용] (해독제 보유 시)
   → 즉시 회복, 호감 +30

2. [내공으로 치료] (내공 5000+ 필요)
   → 회복 성공률 70%
   → 성공: 호감 +40, 신뢰 +30
   → 실패: 상태 악화, 호감 -20

3. [소하린 부르기] (소하린 동행 시)
   → 100% 회복
   → 소하린 호감 +20

4. [병원 후송] (항상 가능)
   → 시간 소모, 호감 +10
```

## 💡 선택지 조합 시스템

### 연속 선택 효과
```
3연속 긍정 선택:
→ "호감 폭발" 보너스 +30

3연속 부정 선택:
→ "관계 파탄" 위기 -50

균형 선택 (긍정/부정/중립):
→ "균형잡힌 관계" 안정감 +15
```

### 캐릭터 조합 효과
```
━━━━━━━━━━━━━━━━━━━━━━━━
상황: 강아란 vs 혈소연 의견 충돌
━━━━━━━━━━━━━━━━━━━━━━━━

1. 강아란 편들기
   → 강아란 호감 +20
   → 혈소연 호감 -15
   → 파티 균열

2. 혈소연 편들기
   → 혈소연 호감 +20
   → 강아란 호감 -15
   → 파티 균열

3. 중재하기 (지능 80+ / 카리스마 70+)
   → 양쪽 호감 +15
   → 파티 화합 +30
   → 리더십 +5

4. "둘 다 틀렸어요" (용기 90+ 필요)
   → 양쪽 호감 -30
   → 하지만 진실 전달
   → 장기적으로 신뢰 +50
```
