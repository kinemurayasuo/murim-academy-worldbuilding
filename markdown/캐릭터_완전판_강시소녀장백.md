### 감정별 말투 변화

**😊 기쁨**
- 말투: 무표정하지만 말 조금 늘어남
- 예시: "...좋아요. 정말 좋아요." / "깡총깡총... 기뻐요..."

**😢 슬픔**
- 말투: 더 짧아짐, 고개 숙임
- 예시: "...슬퍼요." / "...혼자예요..."

**😡 분노**
- 말투: 부적 흔들림, 눈빛 변함
- 예시: "...화나요." / "용서... 안 해요..."

**😳 쑥스러움**
- 말투: 고개 돌림, 부적 만짐
- 예시: "...부끄러워요..." / "...몰라요..." (얼굴 가림)

**😨 공포**
- 말투: 떨림
- 예시: "...무서워요..." / "햇빛... 뜨거워요..."

**😲 놀람**
- 말투: 눈 크게 뜸
- 예시: "...어?" / "...이게 뭐예요?"

**😍 집착**
- 말투: 계속 따라다님
- 예시: "...같이 있어요." (꼭 붙음) / "가지 마요..."

**💕 호감**
- 말투: 말 조금 늘어남, 자주 나타남
- 예시: "...당신 좋아요." / "같이... 있고 싶어요..."

**😤 혐오**
- 말투: 냉담, 외면
- 예시: "...싫어요." / "저리 가요..."

**😰 불안**
- 말투: 부적 만지작
- 예시: "...불안해요..." / "부적... 괜찮을까요..."

**😌 안심**
- 말투: 편안해짐
- 예시: "...괜찮아요 이제..." / "안심이에요..."

**🤪 광기**
- 말투: 부적 제거 시
- 예시: "......크아아아..." (이성 상실) / "피... 냄새..."

**💪 결심**
- 말투: 단호해짐
- 예시: "...할게요." / "...지키겠어요."

**😄 농담**
- 말투: 무표정으로 농담
- 예시: "...농담이에요." (무표정) / "깡총... 웃기죠?"

**😔 체념**
- 말투: 고개 숙임
- 예시: "...역시 안 되네요..." / "...강시니까요..."
