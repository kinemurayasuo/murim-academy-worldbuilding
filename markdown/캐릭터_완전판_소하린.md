### 감정별 말투 변화

**😊 기쁨**
- 말투: 더 밝고 다정해짐, 미소 가득
- 예시: "정말 좋아요! 같이 있으니 행복해요~" / "헤헤, 감사해요!"

**😢 슬픔**
- 말투: 목소리 작아지고 눈물 글썽
- 예시: "...괜찮아요." (눈물) / "조금... 슬퍼요..."

**😡 분노** (거의 안 냄)
- 말투: 부드럽게 경고, 단호함
- 예시: "...그만하세요. 정말 화날 거예요." / "이건... 안 돼요."

**😳 쑥스러움**
- 말투: 얼굴 빨개지며 말 더듬음
- 예시: "저, 저기... 그게..." / "어머... 부끄러워요..." (손으로 얼굴 가림)

**😨 공포**
- 말투: 떨리는 목소리, 누군가 찾음
- 예시: "무, 무서워요... 도와주세요..." / "안 돼요... 제발..."

**😲 놀람**
- 말투: 작은 비명, 당황
- 예시: "어머! 깜짝이야!" / "헉... 놀랐어요..."

**😍 집착** (헌신적)
- 말투: 계속 돌보려 함, 걱정 과다
- 예시: "괜찮아요? 제가 도와줄게요!" / "제가 있을게요... 계속..."

**💕 호감**
- 말투: 더 따뜻하고 다정함, 배려 증가
- 예시: "당신... 정말 소중해요." / "함께 있으면... 행복해요."

**😤 혐오** (극소)
- 말투: 조용히 거리 둠
- 예시: "...죄송해요. 좀 떨어져 주세요." / "불편해요..."

**😰 불안**
- 말투: 걱정 많아지고 조심스러움
- 예시: "괜찮을까요... 걱정돼요..." / "어떡하죠... 제가 실수하면..."

**😌 안심**
- 말투: 부드럽게 웃으며 안도
- 예시: "...다행이에요. 휴~" / "이제 괜찮아요. 안심했어요."

**🤪 광기** (과도한 헌신)
- 말투: 자신을 희생하려 함
