# 무공 비급 목록

## 📜 비급 등급 시스템

### 등급 분류
```
EX급: 전설의 신공 (세계 10개 미만)
SSS급: 절세 신공 (세계 100개)
SS급: 상급 비급 (전국 1,000개)
S급: 고급 비급 (전국 10,000개)
A급: 중상급 무공 (흔함)
B급: 중급 무공 (일반적)
C급: 하급 무공 (기본)
D급: 초급 무공 (입문)
```

### 획득 방법
```
구매:
- 상점 구매 (D~A급)
- 경매 (S~SSS급)
- 암시장 (불법)

보상:
- 퀘스트 보상
- 던전 클리어
- 이벤트 상품
- 랭킹 보상

발견:
- 고대 유적 탐험
- 비밀 장소 발견
- 은사 전수
- 우연히 획득

계승:
- 가문 전승
- 사부 전수
- 문파 입문
```

## 📚 비급 습득 팁

### 효율적 습득
```
1. 기초부터:
   - D급 마스터 → C급...
   - 단계적 상승

2. 특화 선택:
   - 자신에게 맞는 무공
   - 올라운더보다 특화

3. 시너지:
   - 연계 가능한 무공
   - 같은 계열 우선

4. 재능 고려:
   - 자신의 재능에 맞게
   - 무리한 무공 금지
```

### 주의사항
```
위험 무공:
- 마공: 주화입마 위험
- 흡성대법: 정신 오염
- 금지 무공: 법으로 금지

불법 무공:
- 암시장 거래 금지
- 적발 시 처벌
- 학원 퇴학
```
